I’m thrilled to share my latest project: a drone-based vehicle detection system using YOLOv11 and OpenCV, trained on a Roboflow dataset of 3704 images (640x640, YOLOv11 format). It processes aerial footage, generating MJPEG AVI, H.264 MP4, and Xvid AVI for universal compatibility. Key features include real-time detection, stunning heatmaps, and a bird’s-eye view for advanced analytics. Designed for traffic monitoring and smart city surveillance, it offers a modern UI and robust error handling.
