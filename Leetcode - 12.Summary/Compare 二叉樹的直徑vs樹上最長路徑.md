

|**比較維度**|**題目 A：二叉樹的直徑 (Diameter of Binary Tree)**|**題目 B：樹上最長路徑 (Longest Path On The Tree)**|
|---|---|---|
|**資料結構**|二元樹 (`TreeNode` 物件，含 `left`, `right` 指針)|一般無根樹 / 無向圖（用鄰接表 `G` 儲存）|
|**邊的權重**|無權重（每條邊的長度隱式為 `1`）|帶權重（邊長記錄於陣列 `lens`）|
|**演算法核心**|**樹形 DP (Tree DP) / 後序遍歷**|**兩次 DFS (Two-pass DFS)**|
|**DFS 執行次數**|**1 次** (自底向上 Bottom-up 傳遞深度)|**2 次** (自頂向下 Top-down 累加距離)|
|**狀態定義**|`dfs(node)` 回傳該節點向下延伸的最大深度|`dp[i]` 記錄起點到節點 `i` 的總路徑長|
|**直徑計算方式**|`self.max_len = max(max_len, left_depth + right_depth)`|第 2 次 DFS 的 `max(dp)` 即為答案|

## 題目 A 詳解：二叉樹的直徑 (LeetCode 543)

### 1. 範例 `{1, 2, 3, 4, 5}` 的樹狀結構

輸入 `{1, 2, 3, 4, 5}` 構建出的二元樹如下：

Plaintext

```
       1
      / \
     2   3
    / \
   4   5
```

### 2. Code 解法思維與執行步驟 Trace

- **核心 Idea**：任何樹上最長路徑，必然存在一個「最高轉折點（最高頂點 `node`）」。對於任意節點，經過它的最長路徑 = `左子樹深度 + 右子樹深度`。採用後序遍歷（Post-order），子節點回傳自身的深度給父節點，父節點邊計算深度邊更新全局最大值 `max_len`。
    

**步驟 Trace (自底向上 Bottom-Up)：**

1. **節點 4**（葉節點）：`dfs(4)`
    
    - `left_depth = 0`, `right_depth = 0`
        
    - 更新 `max_len = max(0, 0 + 0) = 0`
        
    - 回傳節點 4 的深度：`max(0, 0) + 1 = 1`
        
2. **節點 5**（葉節點）：`dfs(5)`
    
    - `left_depth = 0`, `right_depth = 0`
        
    - 更新 `max_len = max(0, 0 + 0) = 0`
        
    - 回傳節點 5 的深度：`max(0, 0) + 1 = 1`
        
3. **節點 2**：`dfs(2)`
    
    - 收到 `left_depth = 1` (來自 4)，`right_depth = 1` (來自 5)
        
    - 更新 `max_len = max(0, 1 + 1) = 2` （此時經過節點 2 的路徑 $4 \to 2 \to 5$ 長度為 2）
        
    - 回傳節點 2 的深度：`max(1, 1) + 1 = 2`
        
4. **節點 3**（葉節點）：`dfs(3)`
    
    - `left_depth = 0`, `right_depth = 0`
        
    - 回傳節點 3 的深度：`max(0, 0) + 1 = 1`
        
5. **節點 1**（根節點）：`dfs(1)`
    
    - 收到 `left_depth = 2` (來自 2)，`right_depth = 1` (來自 3)
        
    - 更新 `max_len = max(2, 2 + 1) = 3` （此時經過節點 1 的路徑 $4 \to 2 \to 1 \to 3$ 長度為 3）
        
    - 回傳節點 1 的深度：`max(2, 1) + 1 = 3`
        

**最終結果**：`self.max_len = 3`（最長路徑長度為 3）。

## 題目 B 詳解：樹上最長路徑 (Longest Path On The Tree)

### 1. 範例 `starts=[0,0,2,2], ends=[1,2,3,4], lens=[1,2,5,6]` 結構

無向樹拓撲結構與邊權：

Plaintext

```
       1 (邊權 1)
       |
       0
       | (邊權 2)
       2
     /   \
(邊權 5)  (邊權 6)
  /        \
 3          4
```

### 2. Code 解法思維與執行步驟 Trace

- **核心 Idea**：利用樹幾何性質——「從任意點出發到達最遠的點，必定是樹直徑的其中一個端點 $P$」。先由任意起點 `0` 做出發進行第 1 次 DFS 找 $P$，再從 $P$ 發射第 2 次 DFS 尋找最遠點 $Q$。$P \to Q$ 的累積長度即為解答。
    

**步驟 Trace：**

1. **第一次 DFS（以 `0` 為起點，尋找端點 $P$）**：
    
    - 初始 `dp[0] = 0`
        
    - 走訪節點 1：`dp[1] = dp[0] + 1 = 1`
        
    - 走訪節點 2：`dp[2] = dp[0] + 2 = 2`
        
    - 走訪節點 3：`dp[3] = dp[2] + 5 = 7`
        
    - 走訪節點 4：`dp[4] = dp[2] + 6 = 8`
        
    - 第 1 次 DFS 結束後：`dp = [0, 1, 2, 7, 8]`
        
    - 找出最大值索引 `pos = 4`（對應端點 $P = 4$）。
        
2. **第二次 DFS（以端點 `4` 為起點，求解直徑）**：
    
    - 重置 `dp[4] = 0`
        
    - 走訪節點 2：`dp[2] = dp[4] + 6 = 6`
        
    - 走訪節點 0：`dp[0] = dp[2] + 2 = 8`
        
    - 走訪節點 1：`dp[1] = dp[0] + 1 = 9`
        
    - 走訪節點 3：`dp[3] = dp[2] + 5 = 11`
        
    - 第 2 次 DFS 結束後：`dp = [8, 9, 6, 11, 0]`
        
    - 找出最大距離 `max(dp) = 11`（端點 $4 \to 3$，路徑 $4 \to 2 \to 3$，長度 $6 + 5 = 11$）。
        

**最終結果**：`11`。

## 兩題關鍵相異點與轉換關係

1. **圖的結構表示**：
    
    - 題目 A 是典型二元樹結構，節點間只有單向的父找子關係 (`left`/`right`)。
        
    - 題目 B 是一般的無向圖（無根樹），沒有固定上下級，必須先用鄰接表建立雙向邊。
        
2. **演算法互通性**：
    
    - 題目 B 的「兩次 DFS」**可以** 用來解題目 A（只需將二元樹轉成雙向鄰接表，邊權設為 1 即可）。
        
    - 題目 A 的「樹形 DP（一次 DFS）」**也可以** 用來解題目 B（任選一個點當根，一次 DFS 求每個節點向下延伸的最大長度與次大長度相加）。
