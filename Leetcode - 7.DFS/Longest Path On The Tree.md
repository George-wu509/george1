### **LintCode 1469：树上最长路径**

#### **题目描述**

给定一个无向树，其中包含 `n` 个节点和 `n-1` 条边，求树上最长路径的长度。

输入示例：
```python
n = 5
starts = [0, 0, 2, 2]
ends = [1, 2, 3, 4]
lens = [1, 2, 5, 6]

```
对应的树结构：

```
       1 
       | (長度 1)
       0
       | (長度 2)
       2
     /   \
(長度 5) (長度 6)
  /        \
 3          4
```
边的长度：
- 边 0→1 长度为 1。
- 边 0→2长度为 2。
- 边 1→3长度为 4。
- 边 1→4长度为 5。

输出：
`13 （最长路径为 3 → 2 → 4 或 4 → 2 → 3）`

---
lintcode solution:
https://www.lintcode.com/problem/1469/solution/22814
### **DFS 解法**

#### **算法思路**

树上最长路径的长度，也称为树的「直径」，可以通过以下两次 DFS 求解
1. **第一次 DFS**：
    - 从任意节点（如节点 0）出发，找到离其最远的节点 pospospos。
    - 使用一个数组 `dp` 存储从起点到其他节点的路径长度。
2. **第二次 DFS**：
    - 从节点 pospospos 出发，再次运行 DFS，找到离其最远的节点，并记录路径长度。
3. **最长路径**：
    - 第二次 DFS 的结果即为树的直径。

---

**Example 1:**
```python
Input：n=5,starts=[0,0,2,2],ends=[1,2,3,4],lens=[1,2,5,6]
Output：11
解释:
(3→2→4)这条路径长度为`11`，当然(4→2→3)也是一样的。
```

**Example 2:**

Output：13
解释:
(1→0→2→4)这条路径长度为`13`，当然(4→2→0→1)也是一样的。

#### **代码解析**
```python

class Solution:
    G = []  # 邻接表，存储树的结构
    dp = []  # dp 数组，存储每个节点到起点的路径长度

    def dfs(self, u, pre):
        """DFS 遍历，计算从当前节点 u 到其他节点的路径长度"""
        for x in self.G[u]:
            if x[0] != pre:  # 忽略回到父节点的边
                self.dp[x[0]] = self.dp[u] + x[1]  # 更新路径长度
                self.dfs(x[0], u)  # 递归处理子节点

    def longestPath(self, n, starts, ends, lens):
        """主函数：计算树的直径"""
        import sys
        sys.setrecursionlimit(200000)  # 设置递归深度
        self.G = [[] for i in range(n)]  # 初始化邻接表
        self.dp = [0 for i in range(n)]  # 初始化 dp 数组

        # 构建邻接表
        for i in range(n - 1):
            self.G[starts[i]].append([ends[i], lens[i]])
            self.G[ends[i]].append([starts[i], lens[i]])

        # 第一次 DFS，找到离节点 0 最远的节点 pos
        self.dp[0] = 0
        self.dfs(0, 0)
        pos = max(range(n), key=lambda i: self.dp[i])  # 找到最远节点 pos

        # 第二次 DFS，从 pos 出发找到树的直径
        self.dp[pos] = 0
        self.dfs(pos, pos)
        return max(self.dp)  # 返回最长路径

```

求解樹上最長路徑（又稱 **樹的直徑 Tree Diameter**）最經典且高效的方法是 **「兩次 DFS (Two-pass DFS)」**。

## 核心 Idea 與數學原理

在所有邊權皆為非負數的樹中，存在一個重要的幾何性質：

> **「從樹上任意一個節點出發，所能到達最遠的節點，必然是樹的直徑的其中一個端點。」**

基於這個性質，解題邏輯分為兩步：

1. **第一次 DFS**：從任意節點（如 `0` 號點）出發，找到離它最遠的節點 $P$。此時 $P$ 一定是樹直徑的其中一個端點。
    
2. **第二次 DFS**：從端點 $P$ 出發，再次搜尋離 $P$ 最遠的節點 $Q$。$P$ 到 $Q$ 的距離即為整棵樹的最長路徑（樹的直徑）。
    

## 程式碼詳細解析

### 1. 類別變數與 DFS 遞迴函數
```Python
class Solution:
    G = []   # 鄰接表 (Adjacency List)：G[u] 存放與 u 相連的 [鄰居節點, 邊權]
    dp = []  # 距離陣列：dp[i] 記錄從當前 DFS 起點到節點 i 的路徑總長

    def dfs(self, u, pre):
        """DFS 遍歷：u 為當前節點，pre 為父節點"""
        for x in self.G[u]:
            # x[0] 是鄰居節點，x[1] 是邊權
            if x[0] != pre:  # 關鍵：防止走回父節點造成無窮遞迴
                self.dp[x[0]] = self.dp[u] + x[1]  # 累加路徑長度：子節點距離 = 當前距離 + 邊權
                self.dfs(x[0], u)                  # 遞迴走訪子節點，將 u 傳入作為下層的 pre
```

- **`pre` 的作用**：樹結構沒有環，為了避免走回父節點導致無窮迴圈，傳入 `pre` 進行防護，省去了維護 `visited` 陣列的空間開銷。
    

### 2. 主函數 `longestPath`
```Python
    def longestPath(self, n, starts, ends, lens):
        import sys
        sys.setrecursionlimit(200000)  # 提高遞迴深度限制，避免樹退化為單鏈時發生 Stack Overflow

        self.G = [[] for i in range(n)]
        self.dp = [0 for i in range(n)]

        # 1. 建立無向圖的鄰接表
        for i in range(n - 1):
            self.G[starts[i]].append([ends[i], lens[i]])
            self.G[ends[i]].append([starts[i], lens[i]])

        # 2. 第一次 DFS：從 0 號節點出發
        self.dp[0] = 0
        self.dfs(0, 0)
        # 找出 dp 值的最大索引，即離 0 最遠的端點 pos
        pos = max(range(n), key=lambda i: self.dp[i])

        # 3. 第二次 DFS：從端點 pos 出發
        self.dp[pos] = 0
        self.dfs(pos, pos)

        # 4. dp 中的最大值即為樹的直徑
        return max(self.dp)
```

解釋: 
初始化與遞迴限制 (Initialization & Recursion Limit)
```python
import sys sys.setrecursionlimit(200000) # 提高遞迴上限 self.G = [[] for i in range(n)] # 鄰接表 self.dp = [0 for i in range(n)] # 距離紀錄陣列
```
- **`sys.setrecursionlimit(200000)`**：Python 預設系統遞迴深度極限僅約 1000。當樹退化成一條長鏈時（例如 $0 \to 1 \to 2 \to \dots \to N-1$），DFS 會遞迴 $N$ 層引發 `RecursionError`，此行防範系統崩潰。
- **`self.G`**：雙重串列。`self.G[u]` 儲存節點 `u` 的所有鄰接邊，每條邊表示為 `[目標節點, 邊權]`。
- **`self.dp`**：一維陣列。`self.dp[i]` 用於動態記錄「當前 DFS 起點」到「節點 `i`」的累積路徑長度。
```python
for i in range(n - 1):
    self.G[starts[i]].append([ends[i], lens[i]])
    self.G[ends[i]].append([starts[i], lens[i]])
```
- 樹是 **無向圖 (Undirected Graph)**，若節點 $A$ 與節點 $B$ 相連，訊息需雙向傳遞。
- 因此每讀取一條邊，必須同時在 `self.G[starts[i]]` 添加 `ends[i]`，並在 `self.G[ends[i]]` 添加 `starts[i]`。

第一次 DFS：尋找第一個端點 P (First DFS Pass)
```python
self.dp[0] = 0
self.dfs(0, 0)
pos = max(range(n), key=lambda i: self.dp[i])
```
- 設定起點 0 到自身的距離 `dp[0] = 0`。
- 執行 `self.dfs(0, 0)`，以 0 為根節點走訪全樹，計算 0 到其餘所有節點的距離並填入 `dp` 陣列。
- `max(range(n), key=lambda i: self.dp[i])`：利用 `key` 參數走訪索引 `0` 到 `n-1`，找出 `dp` 值最大的節點索引 `pos`。此 `pos` 點即為離 0 最遠的節点 $P$（直徑的端點之一）。

第二次 DFS：計算整棵樹的最長路徑 (Second DFS Pass)
```python
self.dp[pos] = 0
self.dfs(pos, pos)
return max(self.dp)
```
- 將距離陣列重置，設定起點 `self.dp[pos] = 0`。
- 執行 `self.dfs(pos, pos)`，以剛找到的端點 $P$ 為新根節點進行第二次 DFS 遍歷。
- 此時 `self.dp[i]` 代表端點 $P$ 到節點 $i$ 的距離。
- `max(self.dp)` 找出從 $P$ 能到達的最遠距離，該距離即為樹的直徑 $P \to Q$。
```python
def dfs(self, u, pre):
    for x in self.G[u]:
        if x[0] != pre:  # 防回溯關鍵條件
            self.dp[x[0]] = self.dp[u] + x[1]  # 狀態轉移
            self.dfs(x[0], u)  # 往下層遞迴
```
- **參數說明**：`u` 表示「目前所在的節點」，`pre` 表示「來時的父節點」。
- **`if x[0] != pre` (防迴圈機制)**：樹結構中沒有環，但因為是無向圖，`G[u]` 裡必然包含指向父節點 `pre` 的邊。若不加此判斷，DFS 會在父子節點間無限來回遞迴。
- **`self.dp[x[0]] = self.dp[u] + x[1]` (轉移方程式)**：子節點 `x[0]` 到起點的距離 = 父節點 `u` 到起點的距離 + 邊權 `x[1]`。
- **`self.dfs(x[0], u)`**：將當前點 `u` 作為新父節點傳入，繼續深入搜尋子樹。


根據邊的連接關係與邊權畫出結構圖：
```

       |
       0
       | (長度 2)
       2
     /   \
(長度 5) (長度 6)
  /        \
 3          4
```

### 2. 建立鄰接表 `self.G`

程式碼將邊雙向寫入鄰接表，建立完畢後的結構如下：
- `G[0] = [[1, 1], [2, 2]]` （節點 0 連接 1 權重 1，連接 2 權重 2）
- `G[1] = [[0, 1]]`
- `G[2] = [[0, 2], [3, 5], [4, 6]]`
- `G[3] = [[2, 5]]`
- `G[4] = [[2, 6]]`
self.dp = [ 0, 0, 0, 0, 0 ]

### 3. 第一次 DFS：從節點 `0` 出發，尋找第一個最遠端點 `pos`
設定初始距離 `self.dp[0] = 0`，呼叫 `self.dfs(0, 0)`：

|**遞迴順序**|**當前點 u**|**訪問鄰居 x[0]**|**條件 x[0] != pre**|**dp 陣列更新值**|**動作與說明**|
|---|---|---|---|---|---|
|**1**|`0`|`1`|$1 \neq 0$ (True)|`dp[1] = dp[0] + 1 = 1`|深入呼叫 `dfs(1, 0)`|
|**2**|`1`|`0`|$0 \neq 0$ (False)|忽略|阻止走回父節點 `0`，`dfs(1, 0)` 結束回溯|
|**3**|`0`|`2`|$2 \neq 0$ (True)|`dp[2] = dp[0] + 2 = 2`|深入呼叫 `dfs(2, 0)`|
|**4**|`2`|`0`|$0 \neq 0$ (False)|忽略|阻止走回父節點 `0`|
|**5**|`2`|`3`|$3 \neq 0$ (True)|`dp[3] = dp[2] + 5 = 7`|深入呼叫 `dfs(3, 2)`（到達葉節點後回溯）|
|**6**|`2`|`4`|$4 \neq 0$ (True)|`dp[4] = dp[2] + 6 = 8`|深入呼叫 `dfs(4, 2)`（到達葉節點後回溯）|

- **第一次 DFS 結束時的 `dp` 陣列**：`[0, 1, 2, 7, 8]`
- 尋找最大值的索引：`pos = max(range(5), key=lambda i: self.dp[i])`
- 距離最大值為 `8`（位在節點 `4`），找到第一個端點 **`pos = 4`**。

### 4. 第二次 DFS：從端點 `4` 出發，計算樹的直徑

重置 `self.dp[4] = 0`，呼叫 `self.dfs(4, 4)`：

|**遞迴順序**|**當前點 u**|**訪問鄰居 x[0]**|**條件 x[0] != pre**|**dp 陣列更新值**|**說明**|
|---|---|---|---|---|---|
|**1**|`4`|`2`|$2 \neq 4$ (True)|`dp[2] = dp[4] + 6 = 6`|深入呼叫 `dfs(2, 4)`|
|**2**|`2`|`0`|$0 \neq 4$ (True)|`dp[0] = dp[2] + 2 = 8`|深入呼叫 `dfs(0, 2)`|
|**3**|`0`|`1`|$1 \neq 0$ (True)|`dp[1] = dp[0] + 1 = 9`|深入呼叫 `dfs(1, 0)`，隨後回溯|
|**4**|`2`|`3`|$3 \neq 4$ (True)|`dp[3] = dp[2] + 5 = 11`|深入呼叫 `dfs(3, 2)`，隨後回溯|

- **第二次 DFS 結束時的 `dp` 陣列**：`[8, 9, 6, 11, 0]`
- 計算最大值：`return max(self.dp)` 得到 **`11`**。

### 最終計算結果

整棵樹的最長路徑為 **節點 `4` 到節點 `3`**，路徑為 $4 \to 2 \to 3$，總長度為 $6 + 5 = 11$。




## 時間與空間複雜度

- **時間複雜度**：$\mathcal{O}(N)$ 兩次 DFS 各走訪整棵樹一遍，每個節點與邊均被存取常數次。
- **空間複雜度**：$\mathcal{O}(N)$ 鄰接表 `G` 與遞迴深度均需要 $\mathcal{O}(N)$ 空間

---

### **其他解法**

#### 1. **广度优先搜索（BFS）**

- 替代 DFS 的方法是两次 BFS。
- 从任意节点开始进行第一次 BFS，找到最远节点。
- 再从第一次 BFS 的最远节点开始，进行第二次 BFS，得到树的直径。

#### 2. **树形动态规划**

- 使用动态规划计算每个节点的子树中最长路径和与其他子树的最长路径，合并得到直径。

#### 3. **中心拓展法**

- 从树的重心开始，向外扩展，直接计算直径。

---

### **总结**

- **DFS** 是求树的直径最常用的方法，简单高效，时间复杂度为 O(n)O(n)O(n)。
- **BFS** 和 **树形 DP** 是可替代的方法，适用于不同问题场景。

## **为什么需要两次 DFS？**

### **第一次 DFS 的目的：找到最长路径的一个端点**

- 我们 **随便选一个起点**（通常选择 `0`）。
- 从该起点执行 **DFS 计算所有节点的最远距离**，找到 **最远的节点 `pos`**。
- 这个 `pos` 必然是直径的 **其中一个端点**（但不一定是整个树直径的两端）。

### **第二次 DFS 的目的：从 `pos` 再次 DFS，找到最长路径**

- 以 `pos` 为起点，进行 **第二次 DFS**，计算所有节点的距离。
- 这次 DFS 计算出的 **最远距离即为树的直径（最长路径）**。

---

## **如果只执行一次 DFS，会发生什么问题？**

假设我们 **只进行一次 DFS**，从 `0` 开始计算所有节点的距离，然后直接取 `dp` 数组中的最大值，可能会得到错误的结果。

来看一个具体的 **错误案例**：

### **错误示例**

考虑如下树：

markdown

複製編輯

    `0      \       1        \         2        / \       3   4`

其中边权如下：

- (0,1) = 1
- (1,2) = 1
- (2,3) = 5
- (2,4) = 5

---

### **假设只进行一次 DFS**

1. **从 `0` 出发执行 DFS，计算所有节点到 `0` 的距离：**
    
    bash
    
    複製編輯
    
    `dp[0] = 0 dp[1] = 1 dp[2] = 2 dp[3] = 7  # 2 + 5 dp[4] = 7  # 2 + 5`
    
    - 最大距离是 **7**，但这个结果 **不是树的直径**。
2. **正确的直径是什么？**
    
    - 实际上，最长路径应该是 `3 -> 2 -> 4`，长度 `5 + 5 = 10`，但是 **一次 DFS 无法找到这个路径**。

---

## **为什么第二次 DFS 能解决这个问题？**

1. **第一次 DFS 找到的 `pos` 是离 `0` 最远的节点**，它 **一定是直径的其中一个端点**（例如 `3`）。
2. **第二次 DFS 以 `pos` 为起点，找到最远的另一端**，这样才确保得到了真正的直径（如 `3 -> 2 -> 4`）。

---

## **总结**

- **一次 DFS 只能找到“相对于起点最远的点”，但不一定是直径的端点。**
- **两次 DFS 保证了我们从直径的一个端点出发，找到真正的最长路径。**

### **关键点**

✅ **第一遍 DFS**：找到最长路径的一个端点 `pos`。  
✅ **第二遍 DFS**：从 `pos` 出发，找到树的直径（最长路径）。

**这就是为什么方法 1 需要两次 DFS，而不是一次。** 🚀
