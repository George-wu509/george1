
解碼方法 Decode Ways

Leetcode 91 / Lintcode 512 一条包含字母 `A-Z` 的消息通过以下映射进行了 **编码** ： `'A' -> "1"``'B' -> "2"` ...`'Z' -> "26"`

要 **解码** 已编码的消息，所有数字必须基于上述映射的方法，反向映射回字母（可能有多种方法）。例如，`"11106"` 可以映射为：

- `"AAJF"` ，将消息分组为 `(1 1 10 6)`
- `"KJF"` ，将消息分组为 `(11 10 6)`

注意，消息不能分组为 `(1 11 06)` ，因为 `"06"` 不能映射为 `"F"` ，这是由于 `"6"` 和 `"06"` 在映射中并不等价。

给你一个只含数字的 **非空** 字符串 `s` ，请计算并返回 **解码** 方法的 **总数** 。

**样例 1：** 输入：
```Python
s = "12"
```

输出：
```Python
2
```

解释： 它可以解码为 "AB"（1 2）或者 "L"（12），共 2 种。

**样例 2：** 输入：
```Python
s = "226"
```

输出：
```Python
3
```

解释： 它可以解码为 "BZ" (2 26), "VF" (22 6), 或者 "BBF" (2 2 6)，共 3 种。

**样例 3：** 输入：
```Python
s = "06"
```

输出：
```Python
0
```

解释： "06" 无法映射到 "F" ，因为存在前导零（"6" 和 "06" 并不等价）。
```Python
def numDecodings(self, s: str) -> int:
	if not s or s[0] == '0':
		return 0
	n = len(s)
	dp = [0] * (n + 1)
	dp[0] = 1
	dp[1] = 1
	for i in range(2, n + 1):
		one_digit = int(s[i-1:i])
		two_digits = int(s[i-2:i])
		if 1 <= one_digit <= 9:
			dp[i] += dp[i-1]
		if 10 <= two_digits <= 26:
			dp[i] += dp[i-2]
	return dp[n]
```


```Python
def numDecodings(self, s: str) -> int:
	if not s or s[0] == '0':
		return 0
	prev2, prev1 = 1, 1
	for i in range(2, len(s) + 1):
		curr = 0
		if s[i-1] != '0':
			curr += prev1
		if 10 <= int(s[i-2:i]) <= 26:
			curr += prev2
		prev2, prev1 = prev1, curr
	return prev1
```

解釋: step1: 本質是「帶條件限制的爬樓梯」，每次可以選擇解碼 1 個字元（走 1 步）或 2 個字元（走 2 步） step2: 若字串為空或開頭為 `'0'`（如 `"06"`），無法解碼，直接回傳 `0` step3: 初始化 `prev2 = 1`（空字串 `dp[0]`）、`prev1 = 1`（第一個合法字元 `dp[1]`）。以 `s = "226"` 為例，迴圈 `i = 2, 3` step4: `i = 2`（看前兩碼 `"22"`）：

- 單字元 `'2'` 合法（1~9）-> `curr += prev1` (`0 + 1 = 1`)
    
- 雙字元 `"22"` 合法（10~26）-> `curr += prev2` (`1 + 1 = 2`)
    
- 更新變數：`prev2 = 1, prev1 = 2` step5: `i = 3`（看前三碼 `"226"`）：
    
- 單字元 `'6'` 合法（1~9）-> `curr += prev1` (`0 + 2 = 2`)
    
- 雙字元 `"26"` 合法（10~26）-> `curr += prev2` (`2 + 1 = 3`)
    
- 更新變數：`prev2 = 2, prev1 = 3` step6: 迴圈結束，回傳 `prev1 = 3`
    

s = "226" -> result = 3

1. 2, 2, 6 -> "BBF"
    
2. 22, 6 -> "VF"
    
3. 2, 26 -> "BZ" 共 3 种
    

解釋: 考慮最後一步是解碼 1 個數字還是 2 個數字。 方案數 `Dp[i] = 最後1碼獨立解碼的方案數 + 最後2碼合併解碼的方案數`（前提是該 1 碼或 2 碼落在合法範圍內）。

- 1 碼合法條件：`1 <= int(s[i-1]) <= 9`（即不能為 `'0'`）-> 加上 `Dp[i-1]`
    
- 2 碼合法條件：`10 <= int(s[i-2:i]) <= 26`（避免 `'06'` 這類前導零或超過 26）-> 加上 `Dp[i-2]`
    

### **LeetCode 91 / LintCode 512 - Decode Ways（解碼方法）**

這道題目是 **1D 動態規劃（Dynamic Programming, DP）** 的經典代表，也是「爬樓梯問題」的進階變形。同樣是每次走 1 步或 2 步，但這題增加了**合法性判斷（邊界條件）**，特別是字元 `'0'` 的處理。

## **解法解析**

這道題可以轉化為 **帶條件的遞推關係式** 來求解。

### **思路**

1. **觀察規律（與爬樓梯的對比）**
    
    - 在爬樓梯中，`f(n) = f(n-1) + f(n-2)` 無條件成立。
        
    - 在解碼方法中，走到第 `i` 個字元時：
        
        - **單字元解碼（走 1 步）**：只有當當前字元 `s[i-1] != '0'` 時，才能單獨解碼為 `A~I`，此時繼承 `dp[i-1]` 的方法數。
            
        - **雙字元解碼（走 2 步）**：只有當最近兩個字元組成的數字在 `10 ~ 26` 之間時，才能合併解碼為 `J~Z`，此時繼承 `dp[i-2]` 的方法數。
            
2. **發現遞推公式**
    
    - `dp[i]` 代表字串前 `i` 個字元的解碼方法總數：
        
        - 若 `s[i-1] != '0'`：`dp[i] += dp[i-1]`
            
        - 若 `10 <= int(s[i-2:i]) <= 26`：`dp[i] += dp[i-2]`
            
    - **初始條件**：
        
        - `dp[0] = 1`（空字串有 1 種解碼方式，作為 `dp[2]` 累加的基準）
            
        - `dp[1] = 1`（只要 `s[0] != '0'`，第 1 個字元就有 1 種解碼方式）
            
3. **代碼執行流程**
    
    - 先檢查邊界：若 `s` 為空或 `s[0] == '0'`，直接回傳 `0`。
        
    - 建立長度為 `n + 1` 的陣列 `dp`（或使用兩個滾動變數 `prev2`, `prev1`）。
        
    - 從 `i = 2` 遍歷到 `n`，分別檢查 1 碼與 2 碼是否合法並累加方法數。
        
    - 最後返回 `dp[n]`。
        

## **具體舉例**

假設 `s = "226"`，我們的變數變化如下（對照 `dp` 陣列變化）：

|**i**|**當前子字串**|**單字元檢查 (s[i-1])**|**雙字元檢查 (s[i-2:i])**|**dp 狀態**|
|---|---|---|---|---|
|初始化|`""` / `"2"`|-|-|`[1, 1, 0, 0]`|
|`i = 2`|`"22"`|`'2'` 合法 (`+dp[1]`)|`"22"` 合法 (`+dp[0]`)|`[1, 1, 2, 0]`（`1+1=2`）|
|`i = 3`|`"226"`|`'6'` 合法 (`+dp[2]`)|`"26"` 合法 (`+dp[1]`)|`[1, 1, 2, 3]`（`2+1=3`）|

若遇到包含 `0` 的情況，例如 `s = "2101"`：

|**i**|**當前子字串**|**單字元檢查 (s[i-1])**|**雙字元檢查 (s[i-2:i])**|**dp 狀態**|
|---|---|---|---|---|
|初始化|`""` / `"2"`|-|-|`[1, 1, 0, 0, 0]`|
|`i = 2`|`"21"`|`'1'` 合法 (`+1`)|`"21"` 合法 (`+1`)|`[1, 1, 2, 0, 0]`|
|`i = 3`|`"210"`|`'0'` **不合法** (`+0`)|`"10"` 合法 (`+1`)|`[1, 1, 2, 1, 0]`|
|`i = 4`|`"2101"`|`'1'` 合法 (`+1`)|`"01"` **不合法** (`+0`)|`[1, 1, 2, 1, 1]`|

最後返回 `dp[n]`。

## **時間與空間複雜度分析**

- **時間複雜度：O(n)**
    
    - 只需遍歷字串 `s` 一次（長度為 `n`），每次切片與判斷皆為 `O(1)`，因此時間複雜度為 **O(n)**。
        
- **空間複雜度：O(n) / 優化後 O(1)**
    
    - 使用 `dp` 陣列需要 `O(n)` 空間；若使用滾動變數 `prev2` 與 `prev1`，空間複雜度可降至 **O(1)**。
        

## **其他解法**

### **1. 動態規劃 - O(1) 空間優化（面試最推薦）**

- **思路**：
    
    - 觀察轉移方程發現 `dp[i]` 只依賴前兩個狀態 `dp[i-1]` 和 `dp[i-2]`，因此只需用兩個變數滾動更新即可，省去 `O(n)` 陣列開銷。
        
- **時間複雜度**：O(n)
    
- **空間複雜度**：O(1)
    

### **2. 記憶化搜索（DFS + Memoization / Top-Down DP）**

- **思路**：
    
    - 從索引 `index = 0` 開始遞迴往下切分 1 個字元或 2 個字元，並使用雜湊表 `memo[index]` 記錄已計算過的剩餘字串解碼數量，避免重複計算。
        
- **時間複雜度**：O(n)
    
- **空間複雜度**：O(n)（遞迴呼叫棧與 `memo` 空間）
    

## **總結**

- **最直觀的解法**：使用 `O(n)` 陣列 `dp` 記錄前 `i` 個字元的解碼數，邏輯清晰、不易寫錯，時間 `O(n)`，空間 `O(n)`。
    
- **最佳解法（面試首選）**：**O(1) 空間的 DP 滾動變數解法**，時間 `O(n)`，空間 `O(1)`。
    
- **避坑重點**：
    
    1. 字串開頭為 `'0'` 直接回傳 `0`。
        
    2. 遇到 `'0'` 時不能單獨解碼，必須與前一位組成 `"10"` 或 `"20"`；若前一位不是 `'1'` 或 `'2'`（如 `"30"`、`"00"`），則 `curr` 會保持 `0`，最終結果也會正確歸零。

### **進階延伸題：LeetCode 639 - Decode Ways II（解碼方法 II）**

除了數字 `0-9` 外，字串中還可能包含萬用字元 `'*'`，它可以代表 `'1'` 到 `'9'` 中的任意一個數字（注意不包含 `'0'`），求總解碼方法數（結果對 `10^9 + 7` 取模）。

Python

```
class Solution:
    def numDecodings(self, s: str) -> int:
        MOD = 10**9 + 7
        if not s or s[0] == '0':
            return 0
        
        # prev2 對應 dp[i-2], prev1 對應 dp[i-1]
        prev2 = 1
        prev1 = 9 if s[0] == '*' else 1
        
        for i in range(1, len(s)):
            curr = 0
            c1, c2 = s[i - 1], s[i]
            
            # 1. 單字元解碼（c2 獨立解碼）
            if c2 == '*':
                curr = (curr + 9 * prev1) % MOD
            elif c2 != '0':
                curr = (curr + prev1) % MOD
                
            # 2. 雙字元解碼（c1 + c2 合併解碼）
            if c1 == '*' and c2 == '*':
                # ** 可組成 11~19 (9種) + 21~26 (6種) = 15種
                curr = (curr + 15 * prev2) % MOD
            elif c1 == '*':
                # *0 ~ *6 可配 1 或 2 (2種)；*7 ~ *9 只能配 1 (1種)
                curr = (curr + (2 if c2 <= '6' else 1) * prev2) % MOD
            elif c2 == '*':
                # 1* 可配 1~9 (9種)；2* 可配 1~6 (6種)
                if c1 == '1':
                    curr = (curr + 9 * prev2) % MOD
                elif c1 == '2':
                    curr = (curr + 6 * prev2) % MOD
            else:
                # 兩個都是純數字，同 Decode Ways I
                if 10 <= int(s[i - 1:i + 1]) <= 26:
                    curr = (curr + prev2) % MOD
                    
            prev2, prev1 = prev1, curr
            
        return prev1
```
