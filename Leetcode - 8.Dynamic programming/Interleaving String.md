
交錯字串 Interleaving String

Leetcode 97 / Lintcode 29 给定三个字符串 `s1`、`s2`、`s3`，请你帮忙验证 `s3` 是否是由 `s1` 和 `s2` **交错** 组成的。

两个字符串 `s` 和 `t` **交错** 的定义与过程如下，其中每个字符串都会被分割成若干 **非空** 子字符串：

- `s = s_1 + s_2 + ... + s_n`
- `t = t_1 + t_2 + ... + t_m`
- `|n - m| <= 1`
- **交错** 是 `s_1 + t_1 + s_2 + t_2 + s_3 + t_3 + ...` 或者 `t_1 + s_1 + t_2 + s_2 + t_3 + s_3 + ...`

**注意：** `a + b` 意味着字符串 `a` 和 `b` 连接。

**样例 1：** 输入：
```Python
s1 = "aabcc"
s2 = "dbbca"
s3 = "aadbbcbcac"
```

输出：
```Python
True
```

解释： 一种可能的拆分方式为： `s1 = "aa" + "bc" + "c"``s2 = "dbbc" + "a"` 交错组合为：`"aa" + "dbbc" + "bc" + "a" + "c" = "aadbbcbcac"`，因此返回 `True`。

**样例 2：** 输入：
```Python
s1 = "aabcc"
s2 = "dbbca"
s3 = "aadbbbaccc"
```

输出：
```Python
False
```

解释： 没有办法通过交错 `s1` 和 `s2` 的子字符串得到 `s3` 。

**样例 3（长度不匹配或空字符串的边界情况）：** 输入：
```Python
s1 = ""
s2 = ""
s3 = ""
```

输出：
```Python
True
```

解释： 两个空字符串交错后仍为空字符串，匹配成功；若 `len(s1) + len(s2) != len(s3)`，则可直接返回 `False`。

```Python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False
            
        # 確保 s2 為較短字串，將空間複雜度優化至 O(min(m, n))
        if m < n:
            s1, s2 = s2, s1
            m, n = n, m
            
        dp = [False] * (n + 1)
        dp[0] = True
        
        # 初始化第 0 行：只使用 s2 的前 j 個字元匹配 s3
        for j in range(1, n + 1):
            dp[j] = dp[j - 1] and (s2[j - 1] == s3[j - 1])
            
        for i in range(1, m + 1):
            # 更新第 i 行第 0 列：只使用 s1 的前 i 個字元匹配 s3
            dp[0] = dp[0] and (s1[i - 1] == s3[i - 1])
            for j in range(1, n + 1):
                # 狀態轉移：從上方 (使用 s1[i-1]) 或從左方 (使用 s2[j-1]) 轉移而來
                from_s1 = dp[j] and (s1[i - 1] == s3[i + j - 1])
                from_s2 = dp[j - 1] and (s2[j - 1] == s3[i + j - 1])
                dp[j] = from_s1 or from_s2
                
        return dp[n]
```


```Python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        # 標準 2D 動態規劃寫法：O(m * n) 時間，O(m * n) 空間
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False
            
        # dp[i][j] 表示 s1[:i] 與 s2[:j] 能否交錯組成 s3[:i+j]
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True
        
        # 初始化第一列（只取 s1）
        for i in range(1, m + 1):
            dp[i][0] = dp[i - 1][0] and (s1[i - 1] == s3[i - 1])
            
        # 初始化第一行（只取 s2）
        for j in range(1, n + 1):
            dp[0][j] = dp[0][j - 1] and (s2[j - 1] == s3[j - 1])
            
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                dp[i][j] = (dp[i - 1][j] and s1[i - 1] == s3[i + j - 1]) or \
                           (dp[i][j - 1] and s2[j - 1] == s3[i + j - 1])
                           
        return dp[m][n]
```

解釋: step1: 定義狀態 `dp[i][j]` 為「`s1` 的前 `i` 個字元」與「`s2` 的前 `j` 個字元」能否交錯組成「`s3` 的前 `i + j` 個字元」。 step2: 以 `s1 = "ab"`, `s2 = "bc"`, `s3 = "babc"` 為例（`m = 2, n = 2`），初始化一維滾動陣列 `dp = [True, False, False]`。 step3: 填充第 `0` 行（只使用 `s2 = "bc"`）：

- `j = 1`：`dp[0]` 為 `True` 且 `s2[0]('b') == s3[0]('b')` -> `dp[1] = True`
    
- `j = 2`：`dp[1]` 為 `True` 但 `s2[1]('c') != s3[1]('a')` -> `dp[2] = False` 此時第 `0` 行為 `dp = [True, True, False]`。 step4: 進入第 `1` 行（`i = 1`，考慮加入 `s1[0] = 'a'`）：
    
- `j = 0`：`dp[0] = dp[0] and s1[0]('a') == s3[0]('b')` -> `False`
    
- `j = 1`（匹配 `s3[:2] = "ba"`）：上方 `dp[1]` 為 `True` 且 `s1[0]('a') == s3[1]('a')` -> `dp[1] = True`
    
- `j = 2`（匹配 `s3[:3] = "bab"`）：上方 `dp[2]` 為 `False`，左方 `dp[1]` 為 `True` 但 `s2[1]('c') != s3[2]('b')` -> `dp[2] = False` 此時第 `1` 行為 `dp = [False, True, False]`。 step5: 進入第 `2` 行（`i = 2`，考慮加入 `s1[1] = 'b'`）：
    
- `j = 0`：`dp[0] = False`
    
- `j = 1`（匹配 `s3[:3] = "bab"`）：上方 `dp[1]` 為 `True` 且 `s1[1]('b') == s3[2]('b')` -> `dp[1] = True`
    
- `j = 2`（匹配 `s3[:4] = "babc"`）：左方 `dp[1]` 為 `True` 且 `s2[1]('c') == s3[3]('c')` -> `dp[2] = True` step6: 迴圈結束，返回 `dp[2] = True`。
    

解釋: 這道題本質上是**網格路徑可達性問題（類似 Unique Paths）**： 將 `s1` 放在網格縱軸、`s2` 放在橫軸，從左上角 `(0, 0)` 走到右下角 `(m, n)`，每次只能「向下走一步（消耗 `s1` 一個字元）」或「向右走一步（消耗 `s2` 一個字元）」，要求走過的字元序列恰好等於 `s3`。 核心狀態轉移方程： `dp[i][j] = (dp[i-1][j] and s1[i-1] == s3[i+j-1]) or (dp[i][j-1] and s2[j-1] == s3[i+j-1])`。

### **LeetCode 97 - Interleaving String（交錯字串）**

這道題目是 **雙序列二維動態規劃（2D String DP）** 的經典代表作。題目看起來像「將字串拆成多段再交錯拼接」，但其實只要每次從 `s1` 或 `s2` 的開頭依次挑一個字元填入 `s3`，就自動滿足子字串交錯的定義，標準解法為 **二維動態規劃（可壓縮為一維滾動陣列）** 與 **記憶化搜索（DFS + Memoization）**。

## **解法解析**

### **思路**

1. **前置長度剪枝與等價轉化**
    
    - 首先檢查 `len(s1) + len(s2) == len(s3)`，若長度總和不相等，絕對不可能組成 `s3`，直接返回 `False`。
        
    - 題目允許任意切分子字串再交錯，這等價於：**在保持 `s1` 與 `s2` 各自內部字元相對順序不變的前提下，每次從 `s1` 或 `s2` 取出下一個字元，能否拼出 `s3`**。
        
2. **狀態定義與轉移推導**
    
    - 設 `dp[i][j]`（布林值）表示：`s1` 的前 `i` 個字元（`s1[0..i-1]`）和 `s2` 的前 `j` 個字元（`s2[0..j-1]`），是否能交錯組成 `s3` 的前 `i + j` 個字元（`s3[0..i+j-1]`）。
        
    - 要讓 `dp[i][j]` 為 `True`，`s3` 的最後一個字元 `s3[i + j - 1]` 必須要麼來自 `s1` 的第 `i` 個字元，要麼來自 `s2` 的第 `j` 個字元：
        
        1. **來自 `s1`**：`s1[i - 1] == s3[i + j - 1]`，且前面的 `dp[i - 1][j]` 必須為 `True`（從網格上方走下來）。
            
        2. **來自 `s2`**：`s2[j - 1] == s3[i + j - 1]`，且前面的 `dp[i][j - 1]` 必須為 `True`（從網格左方走過來）。
            
3. **空間壓縮（滾動陣列優化）**
    
    - 觀察轉移方程發現，計算第 `i` 行時，只依賴於「上一行同列 `dp[i - 1][j]`」和「當前行前一列 `dp[i][j - 1]`」。
        
    - 因此可以省略第一個維度，只用長度為 `n + 1` 的一維陣列 `dp` 從左到右原地更新；且在進入迴圈前若 `len(s1) < len(s2)`，可先交換兩者，確保額外空間僅為 $O(\min(m, n))$。
        

## **具體舉例**

假設 `s1 = "ab"`，`s2 = "bc"`，`s3 = "babc"`，二維 DP 表格的填表過程（尋找從 `(0, 0)` 到 `(2, 2)` 的合法路徑）如下：

|**s1 \ s2**|**j = 0 ("")**|**j = 1 ("b")**|**j = 2 ("c")**|
|---|---|---|---|
|**`i = 0` (`""`)**|**`True`**（起點）|**`True`**（匹配 `"b"`）|`False`（`"bc" != "ba"`）|
|**`i = 1` (`"a"`)**|`False`（`"a" != "b"`）|**`True`**（從上方下來，匹配 `"ba"`）|`False`（無法匹配 `"bab"`）|
|**`i = 2` (`"b"`)**|`False`|**`True`**（從上方下來，匹配 `"bab"`）|**`True`**（從左方過來，匹配 `"babc"`）|

最終右下角 `dp[2][2]` 為 `True`（路徑為 `(0,0) -> (0,1) -> (1,1) -> (2,1) -> (2,2)`，對應取字元順序 `s2[0]('b') -> s1[0]('a') -> s1[1]('b') -> s2[1]('c')`）。

## **時間與空間複雜度分析**

設 $m$ 為字串 `s1` 的長度，$n$ 為字串 `s2` 的長度。

- **時間複雜度：$O(m \times n)$**
    
    - 雙層迴圈需要遍歷 `(m + 1) * (n + 1)` 個狀態，每個狀態僅進行常數次字元比較與布林運算，總時間複雜度為 **$O(m \times n)$**。
        
- **空間複雜度：$O(\min(m, n))$**
    
    - 透過交換較短字串並使用一維滾動陣列，空間複雜度從標準二維 DP 的 $O(m \times n)$ 優化至 **$O(\min(m, n))$**。
        

## **其他解法**

### **1. 標準二維動態規劃（2D DP）**

- **思路**：
    
    - 直接開闢 `(m + 1) x (n + 1)` 的二維布林陣列 `dp`，分別初始化第 `0` 行與第 `0` 列後，雙層迴圈自頂向下填表。
        
    - 邊界處理更直觀，不需要手動維護 `dp[0]` 的滾動更新。
        
- **時間複雜度**：$O(m \times n)$
    
- **空間複雜度**：$O(m \times n)$
    

### **2. 記憶化搜索（DFS + Memoization / `@lru_cache`）**

- **思路**：
    
    - 定義遞迴函數 `dfs(i, j)` 表示 `s1[i:]` 與 `s2[j:]` 能否組成 `s3[i+j:]`。
        
    - 每次嘗試匹配 `s1[i] == s3[i + j]`（遞迴 `dfs(i + 1, j)`）或 `s2[j] == s3[i + j]`（遞迴 `dfs(i, j + 1)`），並用雜湊表或 `@lru_cache` 緩存已計算過的 `(i, j)` 狀態避免重複分支搜索。
        
- **時間複雜度**：$O(m \times n)$（最多有 $m \times n$ 個不同狀態）。
    
- **空間複雜度**：$O(m \times n)$（遞迴棧深度 $O(m + n)$ 加上緩存表 $O(m \times n)$）。
    

## **總結**

- **最推薦面試寫法**：先寫出 **標準 2D DP**（清晰易懂、不易寫錯索引），若面試官追問空間優化，再順勢改寫為 **一維滾動陣列 DP（$O(\min(m, n))$ 空間）**。
    
- **快速解題技巧**：在 Python 中若想快速驗證思路，**記憶化搜索（`@cache`）** 只需十行代碼即可通過，且只會訪問真正可達的有效狀態，在實際數據中常數時間表現極佳。
    
- **核心思維關鍵**：看到「**兩個字串按順序組合成第三個字串**」，立刻將問題映射為**二維網格 `(i, j)` 走迷宮問題**，每步只能向右或向下移動。

**進階變形題（LeetCode 115 - Distinct Subsequences）：** 給你兩個字串 `s` 和 `t` ，統計並返回在 `s` 的 **子序列** 中 `t` 出現的個數，結果需要對 $10^9 + 7$ 取模（題目保證答案符合 32 位帶符號整數範圍）。

Python

```
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        if m < n:
            return 0
            
        # dp[j] 表示 s 的前 i 个字符的子序列中，t[:j] 出现的次数
        dp = [0] * (n + 1)
        dp[0] = 1  # 空串 t[:0] 在任何字符串中都出现 1 次
        
        for i in range(1, m + 1):
            # 必须从右往左倒序遍历，确保使用的是上一轮（i-1）的 dp[j-1]
            for j in range(min(i, n), 0, -1):
                if s[i - 1] == t[j - 1]:
                    dp[j] += dp[j - 1]
                    
        return dp[n]
```
