
戳氣球 Burst Balloons

LeetCode 312 / LintCode 168 有 `n` 个气球，编号为 `0` 到 `n - 1`，每个气球上都标有一个数字，这些数字存在数组 `nums` 中。

现在要求你戳破所有的气球。戳破第 `i` 个气球，你可以获得 `nums[i - 1] * nums[i] * nums[i + 1]` 枚硬币。这里的 `i - 1` 和 `i + 1` 代表和 `i` 相邻的两个气球的序号。如果 `i - 1` 或 `i + 1` 超出了数组的边界，那么就当它是一个数字为 `1` 的气球。

求所能获得硬币的最大数量。

**样例 1：** 输入：
```Python
nums = [3, 1, 5, 8]
```

输出：
```Python
167
```

解释： nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> [] coins = 3_1_5 + 3_5_8 + 1_3_8 + 1_8_1 = 167

**样例 2：** 输入：
```Python
nums = [1, 5]
```

输出：
```Python
10
```

解释： 先戳破 1，获得 1 * 1 * 5 = 5；再戳破 5，获得 1 * 5 * 1 = 5；總計 5 + 5 = 10。

**样例 3：** 输入：
```Python
nums = [7]
```

输出：
```Python
7
```

解释： 只有一個氣球，左右邊界皆視為 1，獲得 1 * 7 * 1 = 7。
```Python
# 解法一：記憶化搜索（Top-Down DFS + Memoization）
from functools import lru_cache

def maxCoins(self, nums: list[int]) -> int:
    # 在頭尾各加上一個虛擬氣球 1，方便處理邊界
    val = [1] + nums + [1]

    @lru_cache(None)
    def dfs(left: int, right: int) -> int:
        # 開區間 (left, right) 內沒有氣球可戳
        if left + 1 >= right:
            return 0
        best = 0
        # 枚舉區間內「最後一個」被戳破的氣球 k
        for k in range(left + 1, right):
            coins = val[left] * val[k] * val[right]
            best = max(best, dfs(left, k) + coins + dfs(k, right))
        return best

    return dfs(0, len(val) - 1)
```


```Python
# 解法二：區間動態規劃（Bottom-Up Interval DP）
def maxCoins(self, nums: list[int]) -> int:
    val = [1] + nums + [1]
    n = len(val)
    # dp[i][j] 表示戳破開區間 (i, j) 內所有氣球能獲得的最大硬幣數
    dp = [[0] * n for _ in range(n)]

    # i 從下往上遍歷，j 從左往右遍歷，確保計算 dp[i][j] 時子區間已算完
    for i in range(n - 3, -1, -1):
        for j in range(i + 2, n):
            for k in range(i + 1, j):
                total = dp[i][k] + dp[k][j] + val[i] * val[k] * val[j]
                if total > dp[i][j]:
                    dp[i][j] = total

    return dp[0][n - 1]
```

解釋: step1: 為了處理左右邊界，在原陣列前後各補一個 `1`：`val = [1] + nums + [1]`。以 `nums = [3, 1, 5, 8]` 為例，`val = [1, 3, 1, 5, 8, 1]`，長度 `n = 6`（索引 `0` 到 `5`）。 step2: 定義 `dp[i][j]` 為「戳破**開區間 `(i, j)`** 內所有氣球的最大硬幣數」（注意：端點 `i` 和 `j` 本身不被戳破）。 step3: 逆向思考：假設 `k` 是開區間 `(i, j)` 內**最後一個**被戳破的氣球。因為 `(i, k)` 和 `(k, j)` 裡面的氣球都已經先被戳光了，所以此時 `k` 的左右鄰居一定是 `i` 和 `j`，戳破 `k` 獲得 `val[i] * val[k] * val[j]`。 step4: 外層迴圈 `i` 從 `n - 3 = 3` 遞減到 `0`，內層 `j` 從 `i + 2` 遞增到 `5`（先算短區間，再合併成長區間）：

- 當區間長度為 1 個氣球時（如 `(0, 2)` 只有 `k=1`）：`dp[0][2] = 0 + 0 + 1*3*1 = 3`；同理 `dp[1][3] = 3*1*5 = 15`，`dp[2][4] = 1*5*8 = 40`，`dp[3][5] = 5*8*1 = 40`。
    
- 逐步擴大區間直到 `i = 0, j = 5`，枚舉 `k = 1, 2, 3, 4` 取最大值，最終 `dp[0][5] = 167`。 step5: 迴圈結束，返回 `dp[0][n - 1] = 167`。
    

解釋: 這題最難的地方在於**正向思考會導致子問題互相依賴**：如果先戳破第 `k` 個氣球，原本不相鄰的 `k-1` 和 `k+1` 會黏在一起，狀態無法拆分。 只要改用**逆向思考（最後一個戳破誰）**：

1. 假設在開區間 `(i, j)` 中，氣球 `k` 是**最後一個**被戳破的。
    
2. 這意味著左半邊 `(i, k)` 的氣球全部先戳完了，右半邊 `(k, j)` 的氣球也全部先戳完了，左右兩側完全獨立、互不干擾！
    
3. 當場上只剩下 `i`、`k`、`j` 三個氣球時，戳破 `k` 的得分固定為 `val[i] * val[k] * val[j]`，加上左右兩個子區間的最佳解 `dp[i][k] + dp[k][j]`，就得到了完整的狀態轉移方程。
    

### **LeetCode 312 / LintCode 168 - Burst Balloons（戳氣球）**

這道題目是 **區間動態規劃（Interval DP）** 中最經典的「逆向思維」代表作（也是 Blind 75 / NeetCode 150 的核心 Hard 題）。核心突破口在於：**不要想「第一步該戳哪個氣球」，而是想「區間內最後一個被戳破的是哪個氣球」**，藉此切斷左右子問題之間的耦合關係。

## **解法解析**

這道題透過在頭尾補 `1` 建立虛擬邊界，並定義開區間 `(i, j)` 的二維 DP 表格來求解。

### **思路**

1. **觀察規律**
    
    - 題目規定超出邊界的氣球數字視為 `1`，因此直接在原陣列頭尾各插入一個 `1`，變成 `val = [1] + nums + [1]`，問題就等價於：保留頭尾兩個 `1` 不戳，戳光開區間 `(0, n - 1)` 內的所有氣球。
        
    - 如果正向模擬「先戳 `k`」，左右鄰居會動態改變；但如果反過來假設 `k` 是 `(i, j)` 裡**最後一個被戳破的氣球**，那麼在戳 `k` 的那一刻，`(i, k)` 與 `(k, j)` 內部早已清空，`k` 的左右鄰居**必定是 `val[i]` 與 `val[j]`**。
        
2. **發現狀態轉移公式**
    
    - 定義 `dp[i][j]` 為戳破開區間 `(i, j)` 內所有氣球所能獲得的最大硬幣數（其中 `j - i` 至少為 `2`，否則區間內沒有氣球，`dp[i][j] = 0`）：
        
        - `dp[i][j] = max(dp[i][k] + dp[k][j] + val[i] * val[k] * val[j])`，其中 `i < k < j`（`k` 從 `i + 1` 遍歷到 `j - 1`）。
            
3. **代碼執行流程**
    
    - 建立長度為 `n = len(nums) + 2` 的陣列 `val = [1] + nums + [1]`，並初始化 `n x n` 的全零二維陣列 `dp`。
        
    - 因為計算 `dp[i][j]` 需要用到 `dp[i][k]`（同一列左邊）和 `dp[k][j]`（同一行下面），所以外層迴圈 `i` 必須從下往上（`n - 3` 到 `0`）遍歷，內層迴圈 `j` 從左往右（`i + 2` 到 `n - 1`）遍歷（或者改用「區間長度 `length` 從 `2` 到 `n - 1`」遍歷）。
        
    - 最後回傳 `dp[0][n - 1]`。
        

## **具體舉例**

假設 `nums = [3, 1, 5, 8]`，補齊邊界後 `val = [1, 3, 1, 5, 8, 1]`（索引 `0` 到 `5`），關鍵區間的計算過程如下：

|**開區間 (i, j)**|**區間內的氣球**|**枚舉最後戳破的 k 與得分計算**|**dp[i][j] 最大值**|
|---|---|---|---|
|`(0, 2)`|`[3]`|`k=1`：`0 + 0 + 1*3*1 = 3`|`3`|
|`(1, 3)`|`[1]`|`k=2`：`0 + 0 + 3*1*5 = 15`|`15`|
|`(2, 4)`|`[5]`|`k=3`：`0 + 0 + 1*5*8 = 40`|`40`|
|`(3, 5)`|`[8]`|`k=4`：`0 + 0 + 5*8*1 = 40`|`40`|
|`(1, 4)`|`[1, 5]`|`k=2`（先戳5後戳1）：`0 + 40 + 3*1*8 = 64`<br><br>  <br><br>`k=3`（先戳1後戳5）：`15 + 0 + 3*5*8 = 135`|`135`|
|`(0, 4)`|`[3, 1, 5]`|最佳選 `k=3`（最後戳5）：`dp[0][3](30) + 0 + 1*5*8 = 70`|`70`|
|`(0, 5)`|`[3, 1, 5, 8]`|`k=1`：`0 + dp[1][5](159) + 1*3*1 = 162`<br><br>  <br><br>`k=4`（最後戳8）：`dp[0][4](70) + 0 + 1*8*1 = 78`<br><br>  <br><br>最佳為 `k=1`（最後戳3）或透過最優子結構合併得 `167`|`167`|

_(註：最優戳法順序為 `1 -> 5 -> 3 -> 8`，對應最後戳 `8` 時左區間 `(0, 4)` 取先戳 `1` 再戳 `5` 再戳 `3` 的 `15 + 120 + 24 = 159`，加上 `1*8*1 = 8`，總計 `167`。)_

## **時間與空間複雜度分析**

- **時間複雜度：O(n³)**
    
    - 狀態總數為二維區間 `(i, j)`，共有 `O(n²)` 個狀態；計算每個狀態時需要枚舉區間內的分割點 `k`，耗時 `O(n)`，因此總時間複雜度為 **O(n³)**。
        
- **空間複雜度：O(n²)**
    
    - 需要一個 `(n + 2) x (n + 2)` 的二維 DP 陣列來儲存所有開區間的最優解，因此空間複雜度為 **O(n²)**。
        

## **其他解法**

### **1. 記憶化搜索（Top-Down DFS + Memoization）**

- **思路**：
    
    - 直接從最終目標區間 `dfs(0, n - 1)` 往下遞迴，枚舉分割點 `k` 並用二維陣列或 `@lru_cache` 快取已計算過的 `(left, right)` 結果。好處是**不需要煩惱雙重迴圈的遍歷方向**，邏輯最貼近人類直覺。
        
- **時間複雜度**：O(n³)
    
- **空間複雜度**：O(n²)
    

### **2. 暴力回溯法（Brute Force Backtracking）**

- **思路**：
    
    - 每次從剩餘氣球中任選一個戳破並移除元素，遞迴嘗試所有 `n!` 種排列組合並取最大得分（當 `n > 10` 時會嚴重超時 TLE）。
        
- **時間複雜度**：O(n!)
    
- **空間複雜度**：O(n)
    

## **總結**

- **面試首選最佳解法**：**Bottom-Up 區間動態規劃（或 Top-Down 記憶化搜索）**，時間 `O(n³)`，空間 `O(n²)`。在面試現場如果擔心寫錯迴圈方向，先寫記憶化搜索再改寫成二維陣列 DP 是最穩妥的策略。
    
- **常見易錯點**：
    
    1. **正向定義狀態**：想成「`k` 是第一個戳破的氣球」，會導致左右兩側產生依賴而無法寫出狀態轉移方程；務必記住「逆向思維：枚舉最後一個被戳破的氣球 `k`」。
        
    2. **閉區間 vs 開區間混淆**：使用開區間 `(i, j)`（不包含 `i` 和 `j`）可以讓邊界條件最乾淨，直接對應 `val[i] * val[k] * val[j]`。
        
    3. **Bottom-Up 迴圈順序寫反**：如果 `i` 和 `j` 都從小到大遍歷，計算 `dp[i][j]` 時 `dp[k][j]`（`k > i`）還沒被計算出來，會全部讀到初始值 `0`。

### **延伸變形題：切棍子的最小成本（LeetCode 1547）**

這道題幾乎是「戳氣球」的鏡像題：有一根長度為 `n` 的木棍與一組切割點 `cuts`，每次切割的成本等於**當前這段木棍的總長度**，求切完所有指定點的最小總成本。 同樣在頭尾補上 `0` 和 `n` 並排序，枚舉開區間 `(i, j)` 內切下的「第一刀」位置 `k`（切開後左右兩段完全獨立）：

Python

```
class Solution:
    def minCost(self, n: int, cuts: list[int]) -> int:
        # 補上木棍的左右兩端點 0 與 n，並由小到大排序
        cuts = [0] + sorted(cuts) + [n]
        m = len(cuts)
        # dp[i][j] 表示完成開區間 (i, j) 內所有切割點的最小成本
        dp = [[0] * m for _ in range(m)]

        for i in range(m - 3, -1, -1):
            for j in range(i + 2, m):
                dp[i][j] = float('inf')
                for k in range(i + 1, j):
                    cost = dp[i][k] + dp[k][j] + (cuts[j] - cuts[i])
                    if cost < dp[i][j]:
                        dp[i][j] = cost

        return dp[0][m - 1]
```
