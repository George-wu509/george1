
不同路徑 Unique Paths

Leetcode 62 / Lintcode 114 一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

**样例 1：** 输入：
```Python
m = 3
n = 7
```

输出：
```Python
28
```

解释： 从左上角 `(0, 0)` 到右下角 `(2, 6)` ，一共需要走 `2` 步向下和 `6` 步向右，总共有 `28` 条不同的路径。

**样例 2：** 输入：
```Python
m = 3
n = 2
```

输出：
```Python
3
```

解释： 从左上角开始，总共有 3 条路径可以到达右下角。

1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下

**样例 3（单行或单列的边界情况）：** 输入：
```Python
m = 1
n = 5
```

输出：
```Python
1
```

解释： 网格只有一行，机器人只能一直向右走，因此只有 `1` 条路径。

```Python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # 空間優化版 1D 動態規劃：只保留當前行的狀態
        dp = [1] * n
        
        for _ in range(1, m):
            for j in range(1, n):
                # 新的 dp[j] = 上方格子(原 dp[j]) + 左方格子(新 dp[j-1])
                dp[j] += dp[j - 1]
                
        return dp[-1]
```


```Python
import math

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # 排列組合數學解法：總共走 (m - 1) + (n - 1) 步，從中選出 (m - 1) 步向下走
        return math.comb(m + n - 2, m - 1)
```

解釋: step1: 因為機器人每次只能「向下」或「向右」移動，到達任意格子 `(i, j)` 的路徑數，只等於從上方 `(i - 1, j)` 走過來的路徑數，加上從左方 `(i, j - 1)` 走過來的路徑數。 step2: 以 `m = 3, n = 4` 為例，初始化一維陣列 `dp = [1, 1, 1, 1]`（代表第 `0` 行的所有格子都只有 `1` 種走法：一直向右走）。 step3: 進入第 `1` 行（`i = 1`）：

- `j = 1`：`dp[1] = dp[1] + dp[0] = 1 + 1 = 2` -> `dp = [1, 2, 1, 1]`
    
- `j = 2`：`dp[2] = dp[2] + dp[1] = 1 + 2 = 3` -> `dp = [1, 2, 3, 1]`
    
- `j = 3`：`dp[3] = dp[3] + dp[2] = 1 + 3 = 4` -> `dp = [1, 2, 3, 4]` step4: 進入第 `2` 行（`i = 2`）：
    
- `j = 1`：`dp[1] = dp[1] + dp[0] = 2 + 1 = 3` -> `dp = [1, 3, 3, 4]`
    
- `j = 2`：`dp[2] = dp[2] + dp[1] = 3 + 3 = 6` -> `dp = [1, 3, 6, 4]`
    
- `j = 3`：`dp[3] = dp[3] + dp[2] = 4 + 6 = 10` -> `dp = [1, 3, 6, 10]` step5: 迴圈結束後，返回最後一格 `dp[-1] = 10`。
    

解釋: 這道題是 **2D 網格動態規劃（Grid DP）** 的最經典入門題。 由於移動方向被嚴格限制為「只能向右或向下」，網格構成了一個天然的**有向無環圖（DAG）**，不存在回頭路，滿足無後效性。 狀態轉移方程為：`dp[i][j] = dp[i - 1][j] + dp[i][j - 1]`（第一行與第一列的邊界值均為 `1`）。

### **LeetCode 62 - Unique Paths（不同路徑）**

這道題目是 **二維網格動態規劃（2D Dynamic Programming）** 與 **組合數學（Combinatorics）** 的經典模板題。問題要求計算從 `m x n` 網格左上角走到右下角的總路徑數，標準解法為 **一維滾動陣列 DP** 與 **組合數公式**。

## **解法解析**

### **思路**

1. **確定狀態定義**
    
    - 設 `dp[i][j]` 表示機器人從起點 `(0, 0)` 出發，到達座標 `(i, j)` 的不同路徑總數。
        
2. **推導狀態轉移方程**
    
    - 題目規定機器人每次只能**向下**或**向右**移動一步。
        
    - 因此，想要抵達 `(i, j)`，最後一步只有兩種可能：
        
        1. 從正上方 `(i - 1, j)` 向下走 1 步到達。
            
        2. 從正左方 `(i, j - 1)` 向右走 1 步到達。
            
    - 根據加法原理，到達 `(i, j)` 的總路徑數為兩者之和： `dp[i][j] = dp[i - 1][j] + dp[i][j - 1]`
        
3. **初始化邊界條件與空間優化**
    
    - **第一行 `dp[0][j]`**：只能一直向右走，所以全部為 `1`。
        
    - **第一列 `dp[i][0]`**：只能一直向下走，所以全部為 `1`。
        
    - **空間壓縮（1D 陣列）**：計算第 `i` 行的數據時，我們只需要用到「上一行同列 `dp[j]`」和「當前行前一列 `dp[j - 1]`」。因此可以直接在一個長度為 `n` 的一維陣列 `dp` 上從左到右原地覆蓋更新，將空間複雜度從 $O(m \times n)$ 降至 $O(n)$。
        

## **具體舉例**

假設 `m = 3, n = 4`，二維網格中每個位置的路徑數填表過程如下：

|**行 / 列**|**j = 0（邊界）**|**j = 1**|**j = 2**|**j = 3**|
|---|---|---|---|---|
|**`i = 0`（初始行）**|`1`|`1`|`1`|`1`|
|**`i = 1`**|`1`|`1 + 1 = 2`|`1 + 2 = 3`|`1 + 3 = 4`|
|**`i = 2`**|`1`|`2 + 1 = 3`|`3 + 3 = 6`|`4 + 6 = 10`|

最終右下角 `(2, 3)` 的值為 `10`，表示共有 **10 種** 不同的路徑。

## **時間與空間複雜度分析**

設網格高度為 $m$，寬度為 $n$。

- **時間複雜度：$O(m \times n)$**
    
    - 需要雙層迴圈遍歷網格中除第一行與第一列外的 $(m - 1) \times (n - 1)$ 個格子，每個格子耗時 $O(1)$，總時間複雜度為 **$O(m \times n)$**。
        
- **空間複雜度：$O(n)$**
    
    - 透過滾動陣列優化，只需維護一個長度為 $n$ 的一維陣列 `dp`（若進一步取 `min(m, n)` 作為陣列長度，空間複雜度可優化至 $O(\min(m, n))$）。
        

## **其他解法**

### **1. 標準二維動態規劃（2D DP）**

- **思路**：
    
    - 直接建立大小為 `m x n` 的二維矩陣 `dp`，將第一行與第一列初始化為 `1`，雙層迴圈填滿整個矩陣並返回 `dp[m - 1][n - 1]`。
        
    - 雖然空間複雜度為 $O(m \times n)$，但在處理帶障礙物或複雜狀態轉移時最直觀、最不易出錯。
        
- **時間複雜度**：$O(m \times n)$
    
- **空間複雜度**：$O(m \times n)$
    

### **2. 排列組合數學公式（Combinatorics）**

- **思路**：
    
    - 從左上角 `(0, 0)` 到右下角 `(m - 1, n - 1)`，無論怎麼走，機器人都**必須總共向下走 `m - 1` 步，向右走 `n - 1` 步**，總步數固定為 `m + n - 2` 步。
        
    - 問題等價於：在總共 `m + n - 2` 步的移動序列中，挑選 `m - 1` 個位置放「向下」（其餘自動為「向右」），共有多少種組合方式。
        
    - 答案即為組合數公式：$\binom{m + n - 2}{m - 1} = \frac{(m + n - 2)!}{(m - 1)!(n - 1)!}$。
        
- **時間複雜度**：$O(\min(m, n))$（計算組合數分子分母連乘所需的步數）。
    
- **空間複雜度**：$O(1)$。
    

## **總結**

- **最推薦面試寫法**：**一維滾動陣列 DP**，時間複雜度 $O(m \times n)$，空間複雜度 $O(n)$，兼具可讀性與空間效率，且容易擴展到帶障礙物的進階題。
    
- **最極致效能解法**：**組合數公式 `math.comb(m + n - 2, m - 1)`**，空間複雜度 $O(1)$，但僅適用於無障礙物且規則對稱的純網格。
    
- **核心思維關鍵**：網格 DP 的核心在於「**當前格子的狀態由上方與左方推導而來**」，當狀態轉移僅依賴上一行時，永遠可以壓縮為一維陣列。

**進階變形題（LeetCode 63 - Unique Paths II）：** 一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 “Start” ）。机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish”）。现在考虑网格中有障碍物（用 `1` 表示，空位用 `0` 表示）。那么从左上角到右下角将会有多少条不同的路径？

Python

```
from typing import List

class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        # 若起点或终点本身就是障碍物，直接返回 0
        if not obstacleGrid or obstacleGrid[0][0] == 1 or obstacleGrid[-1][-1] == 1:
            return 0
            
        m, n = len(obstacleGrid), len(obstacleGrid[0])
        dp = [0] * n
        dp[0] = 1  # 起点路径数为 1
        
        for i in range(m):
            for j in range(n):
                if obstacleGrid[i][j] == 1:
                    # 遇到障碍物，此路不通，路径数清零
                    dp[j] = 0
                elif j > 0:
                    # 非第一列且无障碍物：当前路径数 = 上方(原 dp[j]) + 左方(新 dp[j-1])
                    dp[j] += dp[j - 1]
                    
        return dp[-1]
```
