
LeetCode 763 / LintCode 1045 給定一個只包含小寫英文字母的字串 `s`。我們要把這個字串劃分為**盡可能多的片段**，使得**同一種字母最多只出現在一個片段中**。

請注意，劃分後的片段按順序連接起來，必須能還原回原本的字串 `s`。

請回傳一個整數列表，代表每個字串片段的**長度**。

**样例 1：** 输入：
```Python
s = "ababcbacadefegdehijhklij"
```

输出：
```Python
[9, 7, 8]
```

解释： 劃分結果為 `"ababcbaca"`、`"defegde"`、`"hijhklij"`。 每個字母最多出現在其中一個片段中。 像 `"ababcbacadefegde"`、`"hijhklij"` 這樣的劃分是錯誤的，因為劃分的片段數較少。

**样例 2：** 输入：
```Python
s = "eccbbbbdec"
```

输出：
```Python
[10]
```

解释： 字元 `'e'` 出現在索引 `0` 和索引 `8`，字元 `'c'` 出現在索引 `1, 2, 9`，所有字母交錯在一起，因此整個字串必須合併為同一個片段，長度為 `10`。

**样例 3：** 输入：
```Python
s = "abcdef"
```

输出：
```Python
[1, 1, 1, 1, 1, 1]
```

解释： 每個字元都只出現一次，彼此完全獨立，因此可以切成 6 個長度為 `1` 的片段。

```Python
class Solution:
    def partitionLabels(self, s: str) -> list[int]:
        # 1. 紀錄每個字元在字串中「最後一次出現」的索引位置
        last_index = {c: i for i, c in enumerate(s)}

        res = []
        start = 0  # 當前片段的起始索引
        end = 0    # 當前片段必須延伸到的最遠邊界

        # 2. 線性掃描並動態更新當前片段的最遠右邊界
        for i, c in enumerate(s):
            end = max(end, last_index[c])
            # 當目前索引追上最遠邊界，代表該區間內所有字元都不會再出現於後方
            if i == end:
                res.append(end - start + 1)
                start = i + 1

        return res
```


```Python
# 另一種寫法：轉化為「合併區間（Merge Intervals）」問題
class Solution:
    def partitionLabels(self, s: str) -> list[int]:
        # 紀錄每個字元第一次與最後一次出現的 [start, end] 區間
        intervals = {}
        for i, c in enumerate(s):
            if c not in intervals:
                intervals[c] = [i, i]
            else:
                intervals[c][1] = i

        # 依出現順序（即起始索引遞增）合併重疊區間
        merged = []
        for start, end in intervals.values():
            if not merged or start > merged[-1][1]:
                merged.append([start, end])
            else:
                merged[-1][1] = max(merged[-1][1], end)

        return [end - start + 1 for start, end in merged]
```

解釋: step1: 先掃描一次字串，用雜湊表 `last_index` 記住每個字母「最後一次出現的索引」（例如 `s = "abacdc"`，則 `last_index = {'a': 2, 'b': 1, 'c': 5, 'd': 4}`） step2: 初始化當前片段起點 `start = 0`、當前片段最遠必須到達的終點 `end = 0` step3: `i = 0`（字元 `'a'`）：因為 `'a'` 最後出現在索引 `2`，所以這個片段至少要包到 `2`，更新 `end = max(0, 2) = 2`（此時 `i != end`，繼續往右看） step4: `i = 1`（字元 `'b'`）：`'b'` 最後出現在 `1`，更新 `end = max(2, 1) = 2`（依然還沒到邊界 `2`） step5: `i = 2`（字元 `'a'`）：`end = max(2, 2) = 2`，此時發現 `i == end`（索引 `2` 追上了最遠邊界 `2`），代表索引 `0~2` 裡的所有字母在後面都絕跡了，立刻切一刀！記錄長度 `2 - 0 + 1 = 3`，並將下一段起點設為 `start = 3` step6: 接著 `i = 3`（`'c'`）把 `end` 推到 `5`，直到 `i = 5` 時 `i == end` 再次切一刀，記錄長度 `5 - 3 + 1 = 3` step7: 所以答案 = `[3, 3]`

解釋: 為什麼只要 `i == end` 就一定可以切分？

因為 `end` 維護的是「從 `start` 到 `i` 這段子字串中，**所有出現過的字母各自最後出現位置的最大值**」。一旦掃描指標 `i` 剛好走到 `end`，意味著這段區間內的所有字元都已經「全數登場完畢」，後方再也不會出現任何一個重複字元，因此在此處切割既合法又能保證片段數量最多（貪心最優選擇）。

### **LeetCode 763 / LintCode 1045 - Partition Labels（劃分字母區間）**

這道題目是 **貪心演算法（Greedy）與雙指標（Two Pointers）** 的經典代表題（NeetCode 150 必考題）。問題表面上是在切割字串，本質上則是**動態維護區間右邊界**，並與「合併區間（Merge Intervals）」有著高度的結構等價性。

## **解法解析**

這道題可以轉化為 **最遠邊界追蹤（Last Occurrence + Greedy）** 來求解。

### **思路**

1. **觀察關鍵約束**
    
    - 題目要求「同一種字母最多只出現在一個片段中」。
        
    - 這代表：只要某個片段包含了字元 `c`，那麼這個片段的右邊界就**絕對不能小於 `c` 最後一次出現的位置**。
        
    - 在擴展右邊界的過程中，沿途遇到的其他字元又會帶來各自新的「最後出現位置」，迫使右邊界不斷向右延伸，直到所有被包進來的字元都到達各自的終點為止。
        
2. **發現貪心策略**
    
    - 為了讓切出來的**片段數量盡可能多**，每當目前的掃描位置 `i` 剛好抵達當前累積的最遠邊界 `end` 時，就應該**立刻切分**，不繼續往後貪圖更多字元。
        
    - 這樣切出的每一個片段都是滿足條件的「最小閉包（Minimal Valid Closure）」。
        
3. **代碼執行流程**
    
    - **第一趟遍歷（預處理）**：建立雜湊表 `last_index`，記錄 `s` 中每個字元最後出現的索引。
        
    - **第二趟遍歷（貪心切割）**：維護 `start = 0`（當前區間起點）和 `end = 0`（當前區間最遠終點）。
        
    - 每次讀取 `s[i]`，更新 `end = max(end, last_index[s[i]])`。
        
    - 當 `i == end` 時，計算區間長度 `end - start + 1` 加入答案，並更新 `start = i + 1`。
        

## **具體舉例**

假設 `s = "ababcbacadefegdehijhklij"`，各字元最後出現位置為： `{'a': 8, 'b': 5, 'c': 7, 'd': 14, 'e': 15, 'f': 11, 'g': 13, 'h': 19, 'i': 22, 'j': 23, 'k': 20, 'l': 21}`。

遍歷過程中的變數變化如下：

|**索引 i**|**字元 c**|**last_index[c]**|**更新後 end**|**是否觸發 i == end**|**動作與結果**|
|---|---|---|---|---|---|
|`0`|`'a'`|`8`|`8`|否|確定第一段至少要延伸到索引 `8`|
|`1 ~ 7`|`'b','a','b','c','b','a','c'`|`5, 8, 5, 7...`|`8`|否|沿途字元的最後位置都在 `8` 以內，`end` 維持 `8`|
|`8`|`'a'`|`8`|`8`|**是**|切分 `"ababcbaca"`，長度 `8 - 0 + 1 = 9`，`start` 更新為 `9`|
|`9`|`'d'`|`14`|`14`|否|第二段邊界推至 `14`|
|`10`|`'e'`|`15`|`15`|否|遇到 `'e'`，邊界再往右擴張至 `15`|
|`11 ~ 14`|`'f','e','g','d'`|`11, 15, 13, 14`|`15`|否|邊界維持 `15`|
|`15`|`'e'`|`15`|`15`|**是**|切分 `"defegde"`，長度 `15 - 9 + 1 = 7`，`start` 更新為 `16`|
|`16 ~ 23`|`'h'...'j'`|`19 ~ 23`|`23`|`i=23` 時觸發|切分 `"hijhklij"`，長度 `23 - 16 + 1 = 8`|

最終返回 `[9, 7, 8]`。

## **時間與空間複雜度分析**

- **時間複雜度：$O(n)$**
    
    - 需要兩次線性掃描字串 `s`（第一次建立 `last_index`，第二次進行貪心切割），每次操作皆為 $O(1)$，總時間複雜度為 **$O(n)$**。
        
- **空間複雜度：$O(1)$**
    
    - 題目限定字串僅包含小寫英文字母，`last_index` 最多只會儲存 26 個鍵值對（常數空間），輸出陣列 `res` 最多也只有 26 個元素（若不計入回傳值空間），額外輔助空間複雜度為 **$O(1)$**。
        

## **其他解法**

### **1. 區間合併法（Merge Intervals）**

- **思路**：
    
    - 將每個字母視為一個區間 `[first_occurrence, last_occurrence]`（代表這個字母涵蓋的範圍）。
        
    - 題目就完全等價於 **LeetCode 56（Merge Intervals）**：將所有有重疊的字母區間合併成互不相交的大區間，最後計算每個合併後區間的長度。
        
    - 因為我們依字元在 `s` 中首次出現的順序建立區間，這些區間的起點天然就是遞增排序的，連排序步驟都可以省去。
        
- **時間複雜度**：$O(n)$
    
- **空間複雜度**：$O(1)$（最多 26 個區間）
    

## **總結**

- **面試標準最佳解（Greedy + Last Index）**：時間 **$O(n)$**、空間 **$O(1)$**，只需一個雜湊表和兩個指標即可完成，邏輯俐落且無需處理複雜的區間結構。
    
- **思維遷移價值**：當題目出現「**相同元素必須歸在同一個子陣列 / 區間內，求最多能切幾段**」時，第一步永遠是預處理每個元素的**最後出現位置**，再透過動態維護 `max_end` 進行貪心切割。

### **進階變形題：如果要求將字串劃分為「盡可能少」的片段，且每個片段內「不能有重複字元」，該怎麼寫？**

這是經典的對比變形題（對應 **LeetCode 2405 - Optimal Partition of String**）：與本題「相同字元必須在一起」完全相反，變形題要求「相同字元必須分開」，此時只要用一個 `set`（或 26-bit 位元遮罩）記錄當前片段出現過的字元，一旦遇到重複字元就立刻貪心切一刀：

Python

```
class Solution:
    def partitionString(self, s: str) -> int:
        seen = set()
        chunks = 1  # 至少會有 1 個片段

        for c in s:
            if c in seen:
                chunks += 1
                seen.clear()  # 開啟新片段，重置已出現字元集合
            seen.add(c)

        return chunks
```
