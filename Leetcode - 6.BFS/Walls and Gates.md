
LeetCode 286 / LintCode 663 (NeetCode 150)
給你一個 `m x n` 的二維網格 `rooms` ，網格中每個格子包含以下三種可能的值之一：
- `-1` ：表示牆壁或障礙物。
- `0` ：表示一扇門。
- `INF`（`2147483647`，即 `2^31 - 1`）：表示一間空的房間。

請你將每個 **空房間** 填入它到 **最近一扇門** 的距離（每次只能向上、下、左、右四個方向移動一格）。如果某個空房間無法到達任何一扇門，則保持其值為 `INF` 不變。

**樣例 1：**
輸入：
```python
rooms = [
  [2147483647, -1, 0, 2147483647],
  [2147483647, 2147483647, 2147483647, -1],
  [2147483647, -1, 2147483647, -1],
  [0, -1, 2147483647, 2147483647]
]
```
輸出：
```python
[
  [3, -1, 0, 1],
  [2,  2, 1, -1],
  [1, -1, 2, -1],
  [0, -1, 3, 4]
]
```
解釋：
- 右上角 `(0, 3)` 距離門 `(0, 2)` 為 `1` 步。
- 左上角 `(0, 0)` 距離左下角的門 `(3, 0)` 為 `3` 步，距離右上角的門 `(0, 2)` 為 `4` 步，取較小值 `3`。

**樣例 2：**
輸入：
```python
rooms = [[-1]]
```
輸出：
```python
[[-1]]
```
解釋：
網格中只有牆壁，無需任何修改

**樣例 3：**
輸入：
```python
rooms = [
  [2147483647, -1],
  [-1, 2147483647]
]
```
輸出：
```python
[
  [2147483647, -1],
  [-1, 2147483647]
]
```
解釋：
網格中沒有門（或房間被牆壁完全隔絕），所有空房間保持 `INF`

### 解法一：DFS 深度優先搜尋（從每扇門出發，最壞時間 O((m*n)^2)）

```python
class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        if not rooms or not rooms[0]:
            return
        
        ROWS, COLS = len(rooms), len(rooms[0])
        
        def dfs(r: int, c: int, dist: int) -> None:
            # 越界、遇到牆壁，或當前路徑距離沒有比已記錄的更短，直接剪枝返回
            if r < 0 or r >= ROWS or c < 0 or c >= COLS or rooms[r][c] < dist:
                return
            
            rooms[r][c] = dist
            dfs(r + 1, c, dist + 1)
            dfs(r - 1, c, dist + 1)
            dfs(r, c + 1, dist + 1)
            dfs(r, c - 1, dist + 1)
            
        for r in range(ROWS):
            for c in range(COLS):
                if rooms[r][c] == 0:
                    dfs(r, c, 0)
```

### 解法二：多源廣度優先搜尋 Multi-Source BFS（面試最佳解，時間 O(m*n)）

```python
from collections import deque

class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        if not rooms or not rooms[0]:
            return

        ROWS, COLS = len(rooms), len(rooms[0])
        INF = 2147483647
        queue = deque()

        # 1. 先掃描整個網格，將所有「門 (0)」同時放入 Queue 作為 BFS 起點
        for r in range(ROWS):
            for c in range(COLS):
                if rooms[r][c] == 0:
                    queue.append((r, c))

        # 2. 從所有門同步向外逐層擴散
        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        while queue:
            r, c = queue.popleft()
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                # 只要在邊界內且值為 INF，代表是「尚未被任何門拜訪過的空房間」
                if 0 <= nr < ROWS and 0 <= nc < COLS and rooms[nr][nc] == INF:
                    rooms[nr][nc] = rooms[r][c] + 1
                    queue.append((nr, nc))
```

解釋:
step1: 反向思考：如果從每個空房間 (`INF`) 出發找門，需要做很多次重複的 BFS；但如果把 **所有門 (`0`)** 同時放進 Queue 裡一起向外擴散（水波紋擴散），每個空房間 **第一次** 被波紋碰到時，就保證是離它最近的那扇門！
step2: 假設網格為 `3 x 3`：`[[INF, -1, 0], [INF, INF, INF], [0, -1, INF]]`。
step3: 初始化掃描網格，找到兩扇門 `(0, 2)` 與 `(2, 0)`，將它們一起加入 `queue = [(0, 2), (2, 0)]`。
step4: 第一波擴散（處理距離 `0` 的門）：
  - 彈出 `(0, 2)`：上方、右方越界，左方 `(0, 1)` 是牆壁 `-1` 跳過，下方 `(1, 2)` 是 `INF` → 更新 `rooms[1][2] = 0 + 1 = 1`，加入 Queue。
  - 彈出 `(2, 0)`：左方、下方越界，右方 `(2, 1)` 是牆壁 `-1` 跳過，上方 `(1, 0)` 是 `INF` → 更新 `rooms[1][0] = 0 + 1 = 1`，加入 Queue。
  - 此時 `queue = [(1, 2), (1, 0)]`（所有距離門為 `1` 的房間）。
step5: 第二波擴散（處理距離 `1` 的房間）：
  - 彈出 `(1, 2)`：相鄰的 `(1, 1)` 是 `INF` → 更新 `rooms[1][1] = 2`，`(2, 2)` 是 `INF` → 更新 `rooms[2][2] = 2`，兩者加入 Queue。
  - 彈出 `(1, 0)`：相鄰的 `(0, 0)` 是 `INF` → 更新 `rooms[0][0] = 2` 加入 Queue；而 `(1, 1)` 已經變成 `2`（不再是 `INF`），代表已經被更近或等距的門先佔領了，直接跳過！
step6: 第三波擴散：彈出 `(1, 1), (2, 2), (0, 0)`，四周皆無 `INF` 房間，Queue 清空結束，網格原地修改完成。

### **LeetCode 286 - Walls and Gates（牆與門）**

這道題目是圖論演算法中 **「多源廣度優先搜尋（Multi-Source BFS）」** 最具代表性的入門必刷題。本題要求我們在無權重網格（每一步代價皆為 `1`）中計算多起點最短路徑，直接修改原陣列 `rooms` 即可，無需額外回傳值。

---

## **解法解析**

這道題的核心思維在於 **「逆向思維（起點與終點互換）」** 與 **「BFS 層序性質」**。

### **思路**

1. **為什麼不從空房間出發？**
   - 如果對每一個空房間（`INF`）單獨跑一次 BFS 去找最近的門，最壞情況下（幾乎全是空房間、只有 1 扇門），每個房間都要遍歷整張圖，時間複雜度會退化到 **O((m × n)²)**，容易超時（TLE）。
2. **多源 BFS（Multi-Source BFS）的威力**
   - 我們反過來，在一開始就把網格中 **所有的門（`rooms[r][c] == 0`）** 全部塞進同一個 Queue 中。
   - 你可以想像有一個「超級虛擬源點」同時連接著每一扇門。BFS 的性質是 **「按距離由近到遠一層一層向外擴張」**：
     - 第 1 層處理所有距離為 `0` 的格子（門）；
     - 第 2 層處理所有距離為 `1` 的格子；
     - 第 `k` 層處理所有距離為 `k - 1` 的格子。
3. **如何判斷「已訪問過」而不需額外的 `visited` 陣列？**
   - 題目貼心地將未訪問的空房間設為 `INF (2147483647)`。
   - 只要某個相鄰格子 `rooms[nr][nc] == INF`，就代表它 **從來沒有被任何一扇門走訪過**；一旦我們將它更新為 `rooms[r][c] + 1`，它的值就不再是 `INF`，後續其他門的波紋擴散到這裡時就會自動跳過，完美省下 `O(m × n)` 的 `visited` 空間！

---

## **具體舉例**

以樣例 1 的 `4 x 4` 網格為例，觀察 Queue 每一層波紋擴散的變化：

| BFS 擴散層數 | 處理的 Queue 節點（當前距離） | 更新為 `INF -> 新距離` 的空房間 | 說明 |
|---|---|---|---|
| **初始化** | `[(0, 2), (3, 0)]`（距離 `0`） | 無 | 掃描全圖，將兩扇門同時入隊 |
| **第 1 層** | `(0, 2)`, `(3, 0)` | `rooms[0][3] = 1`, `rooms[1][2] = 1`, `rooms[2][0] = 1` | 距離門 `1` 步的房間全部確定 |
| **第 2 層** | `(0, 3)`, `(1, 2)`, `(2, 0)` | `rooms[1][1] = 2`, `rooms[2][2] = 2`, `rooms[1][0] = 2` | 距離門 `2` 步的房間確定（牆壁 `-1` 阻擋擴散） |
| **第 3 層** | `(1, 1)`, `(2, 2)`, `(1, 0)` | `rooms[0][0] = 3`, `rooms[3][2] = 3` | `(0, 0)` 由 `(1, 0)` 率先到達（距離 `3`），比從右上角繞過來（距離 `4`）更近 |
| **第 4 層** | `(0, 0)`, `(3, 2)` | `rooms[3][3] = 4` | 右下角 `(3, 3)` 由 `(3, 2)` 到達（距離 `4`） |
| **第 5 層** | `(3, 3)` | 無 | 周圍無 `INF`，Queue 為空，演算法結束 |

---

## **時間與空間複雜度分析**

- **時間複雜度：O(m × n)**
  - 初始掃描網格尋找所有的門需要 `O(m × n)` 時間。
  - 在 BFS 過程中，因為只有值為 `INF` 的格子會被更新並放入 Queue，所以網格中的每個空房間 **最多只會入隊一次、出隊一次**，每次檢查 4 個方向為 `O(1)`，總操作次數不超過 `4 × m × n`。
  - 因此整體時間複雜度嚴格為 **O(m × n)**。
- **空間複雜度：O(m × n)**
  - 我們直接原地修改 `rooms` 來充當訪問標記，沒有使用額外的 `visited` 二維陣列。
  - 唯一額外空間是 `queue`，在最壞情況下（例如網格中幾乎全是門或同層波紋極寬），Queue 最多同時儲存 `O(m × n)` 個座標，因此空間複雜度為 **O(m × n)**。

---

## **其他解法**

### **1. 深度優先搜尋 + 距離剪枝（DFS with Pruning）**
- **思路**：
  - 遍歷網格找到每扇門 `(r, c)`，呼叫 `dfs(r, c, 0)` 向四個方向遞迴探索。若遇到 `rooms[r][c] < dist`（表示該房間已經有一條更短或等長的路徑到達某扇門），則立即剪枝返回；否則更新 `rooms[r][c] = dist` 並繼續往下遞迴 `dist + 1`。
- **時間複雜度**：最壞情況 **O((m × n)²)**（若多扇門的探索順序不佳，同一個房間可能被不同門反覆覆寫更小的值，導致重複遞迴整張圖）
- **空間複雜度**：**O(m × n)**（遞迴呼叫堆疊的最大深度）

### **2. 單源 BFS（從每個空房間出發找門）**
- **思路**：
  - 遍歷網格，每當遇到一個 `INF` 房間，就啟動一次獨立的 BFS，直到碰到第一個 `0`（門）為止，將步數寫回該房間。
- **時間複雜度**：最壞情況 **O((m × n)²)**（每次 BFS 都需重新配置 `visited` 並走訪大量格子）
- **空間複雜度**：**O(m × n)**

---

## **總結**

- **面試最佳解**：**多源 BFS（Multi-Source BFS）**，時間 `O(m × n)`，空間 `O(m × n)`。
- **解題關鍵口訣**：在無權重圖（網格）中求「多個終點到各個起點的最短距離」時，永遠優先考慮 **把所有終點同時放進 Queue 裡做多源 BFS**，並利用原陣列的初始狀態（如 `INF`）直接作為 `visited` 判斷條件。

### **進階變形題：如果每扇門不僅要算最短距離，還要標記「最近的是哪一扇門的編號」（Voronoi 網格劃分）？**

只要在將門放入 Queue 時，同步為每扇門分配一個唯一 ID（或直接記錄門的座標 `(gate_r, gate_c)`），在多源 BFS 擴散時一併把門的來源傳遞下去即可：

```python
from collections import deque

class Solution:
    def nearestGateOwner(self, rooms: List[List[int]]) -> List[List[tuple]]:
        ROWS, COLS = len(rooms), len(rooms[0])
        INF = 2147483647
        # owner[r][c] 記錄離 (r, c) 最近的門座標，若無法到達則為 None
        owner = [[None] * COLS for _ in range(ROWS)]
        queue = deque()

        for r in range(ROWS):
            for c in range(COLS):
                if rooms[r][c] == 0:
                    owner[r][c] = (r, c)
                    queue.append((r, c))

        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        while queue:
            r, c = queue.popleft()
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < ROWS and 0 <= nc < COLS and rooms[nr][nc] == INF:
                    rooms[nr][nc] = rooms[r][c] + 1
                    owner[nr][nc] = owner[r][c]  # 繼承最近門的座標來源
                    queue.append((nr, nc))

        return owner
```
