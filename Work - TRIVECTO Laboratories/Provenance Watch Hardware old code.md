#### 1. 自動光學檢測 (AOI) 系統

這是一個非常專業的自動光學檢測 (AOI) 系統應用場景。根據你提供的 MATLAB 代碼和應用背景（Rolex 手錶、多部位拍照、特徵辨識），我可以推斷出這套系統的運作原理。

這套系統的核心在於**「如何透過手錶的玻璃（鏡面）準確對焦到錶盤（Dial）或指針上的特徵」**。

普通的距離感測器（如超音波或簡單紅外線）只能測到玻璃表面。但為了辨識錶盤上的特徵（如 Rolex 的皇冠標誌、字體），相機必須對焦在玻璃下方的錶盤上。因此，這裏使用的應該是**共焦位移感測器 (Spectral Confocal Displacement Sensor)** 或高階的**雷射位移感測器**。這類感測器能穿透透明物體，並同時測量多層介面的距離。

以下為你詳細解釋其原理與代碼分析。

---

### 1. 系統運作原理：多層膜測量 (Multi-layer Measurement)

這些代碼在與一個支援 TCP/IP 通訊的工業控制器（IP: `169.254.64.64`）對話。從指令格式來看，極有可能是 **Keyence（基恩斯）** 或類似等級（如 Opto-Engineering, SICK, OMRON）的高精度光譜共焦感測器。

#### 物理現象解釋：

當光線照射到手錶時，會產生多個反射訊號（Peak）：

1. **Peak 1 (First Object Hit):** 玻璃的最外層表面。
    
2. **Peak 2:** 玻璃的內層表面（與空氣的交界）。
    
3. **Peak 3 / Last Object Hit:** 玻璃下方的物體，即**錶盤 (Dial)** 或 **指針**。
    

#### 為什麼代碼需要這麼複雜的邏輯？

- **折射率修正：** 光線穿過玻璃（藍寶石水晶或礦物玻璃）時會發生折射。如果你直接用感測器讀到的「物理距離」去移動相機，對焦會不準，因為光在玻璃中行走的速度與空氣不同。
    
- **有無玻璃的判斷：** 拍攝錶殼、錶帶或拆開的手錶時，沒有玻璃；拍攝錶頭正面時，有玻璃。系統需要自動判斷現在看到的是「金屬表面」還是「玻璃下的錶盤」。
    

---

### 2. 通訊協議解碼

所有代碼都使用 TCP/IP 發送 Hex 指令。讓我們解碼這些指令：

- `0x4D, 0x53, 0x2C, 0x31, 0x2C, 0x31, 0x0D`
    
    - ASCII 對應：`M`, `S`, `,`, `1`, `,`, `1`, `<CR>`
        
    - 指令：**`MS,1,1`**
        
    - 含義：這通常代表 **"Measure Single" (單次測量)**，後面的參數 `1,1` 代表請求 **OUT1 (第1個輸出值)**。
        

同理：

- `MS,1,2` -> 請求 **OUT2** (設定為玻璃厚度)。
    
- `MS,1,3` -> 請求 **OUT3** (設定為第一層表面，即玻璃表面)。
    
- `MS,1,4` -> 請求 **OUT4** (設定為更深層的反射，或特定計算值)。
    

---

### 3. 詳細代碼分析

#### (1) `watch_sensordistance.m` (基礎測距)

這是最基本的讀取功能，讀取感測器的 **OUT1**。

- **功能：** 獲取當前感測器認為的「主要目標距離」。在感測器設定中，OUT1 通常被設定為「Last Object Hit（最後一個反射峰）」，也就是**錶盤的距離**。
    
- **代碼解讀：**
    
    - `s1=tcpclient(...)`: 連接感測器。
        
    - `write(s1,...)`: 發送 `MS,1,1` 指令。
        
    - `data=read(s1,11)`: 讀回11個 bytes 的數據。
        
    - `b=a(4:end)`: 去掉回應的前3個字符（通常是回應頭，如 "MS,"），只留數值。
        
    - `str2double(b)`: 將字串轉為數字距離。
        

#### (2) `watch_sensordistance2.m` (玻璃厚度)

- **功能：** 讀取 **OUT2**。
    
- **物理意義：** 在感測器控制器端，OUT2 被設定為計算 **(Layer 2 - Layer 1)** 或類似的厚度運算。這回傳的是**玻璃的厚度**。這對於後續的光學折射補償非常重要。
    

#### (3) `watch_sensordistance3.m` (玻璃表面)

- **功能：** 讀取 **OUT3**。
    
- **物理意義：** OUT3 被設定為 **First Object Hit**，也就是**玻璃的最上層表面**。這是為了知道手錶最頂端在哪裡，防止相機鏡頭撞到手錶。
    

#### (4) `watch_sensordistance_combined.m` (核心邏輯：自動對焦修正)

這是最關鍵的腳本，它試圖解決「多層反射」造成的誤判。

- **讀取數據：** 它一次讀取了四個值：
    
    - `sensordist1` (OUT1): 預設的測量距離（通常是錶盤）。
        
    - `sensordist3` (OUT3): 第一層表面（玻璃頂）。
        
    - `sensordist4` (OUT4): 第三個反射物體（可能也是錶盤，或是指針）。
        
    - `sensordist2` (OUT2): 玻璃厚度。
        
- **校正邏輯 (Correction Logic)：**
    
    - **情境 A：判斷讀數是否異常** `if abs(sensordist1-sensordist4)>0.001 && sensordist4>-20` 如果 OUT1 和 OUT4 不一致，且 OUT4 數值合理，程式選擇相信 OUT4 (`sensordist1=sensordist4`)。這可能是因為感測器有時候會把玻璃反光誤判為 OUT1，所以這裡強制修正為更深層的訊號。
        
    - **情境 B：根據玻璃折射率進行補償** `sensordist1=sensordist1-0.39;` 如果檢測到數據有特定差異（可能是因為玻璃材質造成的焦距偏移），程式會人為減去 `0.39mm`。這是一個**經驗校正值**。因為光線經過玻璃後，感測器測到的「光學距離」會比「物理距離」長，必須減去這個值，相機才能真正對焦清楚。
        
- **有無玻璃判斷 (Glass Detection)：**
    
    Matlab
    
    ```
    if abs(sensordist1-sensordist3)<0.001 % 1 peak
        hasglass=0; % 距離一樣，代表只有一個反射面 -> 沒玻璃
    else % 3 peak
        hasglass=1; % 距離不同，代表有分層 -> 有玻璃
    end
    ```
    
    - 如果「最上層距離」和「最底層距離」幾乎一樣（差值 < 0.001），代表光線沒有穿透任何東西，這是一塊實心金屬（如錶殼），所以 **No Glass**。
        
    - 如果有差異，代表光線穿過了介質，所以 **Has Glass**。
        

#### (5) `watch_sensordistance_combined2.m` (進階版)

這是前一個腳本的優化版，邏輯類似，但變數命名更清晰：

- 它明確輸出了四個參數：
    
    1. `sensordistlast` (最後一層，即對焦目標)
        
    2. `hasglass` (有無玻璃)
        
    3. `sensordistfirst` (第一層，安全高度)
        
    4. `glassthick1` (玻璃厚度)
        
- **校正差異：** 這裡有一行 `sensordist1=sensordist1+0.3`，這可能針對不同批次的感測器校正，或是針對不同款式的錶（例如拱形玻璃 vs 平面玻璃）所做的調整。
    

---

### 總結

這個系統的原理是利用**光譜共焦感測器**的穿透特性，透過 TCP/IP 指令讀取手錶的**表面位置**、**玻璃厚度**以及**錶盤深度**。

**Matlab Code 的主要任務是：**

1. **區分材質：** 自動判斷現在拍的是「有玻璃的錶面」還是「金屬錶殼」。
    
2. **計算真實焦距：** 由於玻璃折射會欺騙相機的自動對焦，這些代碼透過讀取感測器的多層數據，並加上校正參數（如 `-0.39` 或 `+0.3`），計算出相機鏡頭真正應該移動到的位置 (Z-axis position)，確保拍出來的 Rolex 皇冠標誌或字體是清晰銳利的。





#### 2. X射線螢光光譜分析

這組 MATLAB 代碼的核心功能並非圖像處理，而是**X射線螢光光譜分析 (XRF, X-ray Fluorescence) 的數據處理系統**。

雖然你提到系統主要功能是用 Camera 拍照辨識特徵，但這部分代碼明顯是用來處理來自 **Olympus Vanta** 手持式 XRF 分析儀（代碼中出現 `Vanta` 字樣）的化學元素數據。這通常用於**鑑定手錶材質真偽**（例如確認是否為真金、904L 鋼、鈦金屬或鉑金）。

以下是詳細的原理說明與代碼分析：

### 1. 系統運作原理：XRF 材質分析

這套代碼是自動化材質檢測流程的一部分。在手錶自動檢測機台中，除了相機外，可能還集成了一個 XRF 探頭，或者這是一個並行的檢測步驟。

- **輸入數據：** 來自 Olympus Vanta 分析儀輸出的 CSV/Excel 原始檔。
    
- **物理意義：** XRF 會發射 X 光照射手錶金屬表面，激發元素的特徵螢光。儀器會計算各種元素（如 Au 金, Pt 鉑, Fe 鐵, Ni 鎳等）的濃度百分比 (`Concentration`) 以及測量誤差 (`Standard Deviation`)。
    
- **核心邏輯：** 代碼將原始數據進行清洗，過濾掉「雜訊」（含量極低或誤差過大的元素），最後判斷出這塊金屬的主要成分（例如：18K金、316L不鏽鋼），並將其與手錶的身份 ID 綁定存入數據庫。
    

---

### 2. 詳細代碼介紹

我將代碼分為**數據清洗**、**文件讀取**、**格式解析**與**資料庫儲存**四個部分來解釋。

#### (1) `watch_material_concentration.m` (核心算法：濾除雜訊)

這是最關鍵的數學處理函數，用來決定哪些元素是「真實存在」的。

- **閾值設定：**
    
    - `matconthresth=0.025`: 濃度閾值。元素濃度必須大於 0.025% 才算數。
        
    - `con2stdthresh=4`: 信噪比閾值。濃度數值必須是其標準差 (Error/Std) 的 4 倍以上。這確保讀數是可靠的，而不是背景雜訊。
        
- **流程：**
    
    1. 遍歷 53 種可能的化學元素（從 Mg 鎂 到 U 鈾）。
        
    2. 檢查每個元素的濃度與誤差是否滿足上述兩個條件。
        
    3. `sort(..., 'descend')`: 將通過篩選的元素按濃度從高到低排序（例如不鏽鋼會顯示：Fe > Cr > Ni > Mo）。
        
- **輸出：** 整理好的主要成分列表 (`matinitlist`) 和其濃度。
    

#### (2) `watch_material_file_process.m` (自動抓取最新數據)

這個腳本負責自動化讀取儀器輸出的文件。

- **路徑鎖定：** `strcat(basefile,'materialsraw\Vanta\exports\')` 指向 Vanta 分析儀的導出資料夾。
    
- **智能讀取：**
    
    - 它會掃描目錄下所有文件。
        
    - 利用 `[~,newestfiles1]=max(dates)` 找到**最新產生**的那個檔案（剛測完的那個）。
        
    - 讀取後，它會執行 `delete(...)` 刪除舊文件或已處理文件，保持資料夾整潔，避免重複讀取。
        

#### (3) `watch_material_modify.m` (解析器：處理不同檢測模式)

XRF 儀器有不同的檢測模式（如貴金屬模式、合金模式），每種模式輸出的表格格式（欄位位置）都不同。這個腳本負責「標準化」這些數據。

- **模式識別：**
    
    - `Geochem(3-Beam)`: 地球化學模式，通常掃描非常詳細的微量元素。
        
    - `AlloyPlus`: 合金模式，針對工業金屬（如不鏽鋼 316L vs 904L）。
        
    - `Precious Metals`: 貴金屬模式，專注於金 (Au)、銀 (Ag)、鉑 (Pt)。
        
- **數據映射 (Mapping)：**
    
    - 代碼中有大量的 `alloyarray1=materialdataraw(19:8:338)`，這是因為原始數據是將元素並排顯示的。代碼利用固定的間隔（步長為 8）來提取每個元素的濃度與誤差值。
        
    - 它還會提取儀器元數據：檢測時間、儀器序列號、準確度等。
        

#### (4) `watch_material_savetodb.m` (資料庫存檔)

將處理好的化學數據與手錶的「身分證」綁定。

- **Metadata 綁定：**
    
    - `watchmeta1`: 包含品牌 (Rolex)、型號 (Reference)、序號 (Serial)、錶徑、材質等。
        
    - `materialmeta1`: 包含這次檢測的具體部位 ID (PartID，例如 "錶扣" 或 "錶殼側面")、檢測時間、地點。
        
- **結構化儲存：** 最終將所有資訊打包成一個 Cell Array (`materialfile`) 並存成 `.mat` 檔，方便後續大數據分析或生成證書。
    

#### (5) `watch_materials_master.m` (總指揮)

這是主程式 (Main Script)，負責串聯以上所有步驟：

1. 呼叫 `watch_material_file_process` 抓取最新文件。
    
2. 呼叫 `watch_material_modify` 解析數據格式。
    
3. 呼叫 `watch_material_concentration` 計算有效成分。
    
4. 最後輸出乾淨的化學成分列表 (`materialnames`)。
    

---

### 總結

這套 MATLAB 代碼是你的手錶 AOI 系統中的**「化學指紋」分析模組**。

- **應用場景：**
    
    - **分辨 Rolex 鋼材：** 區分 Rolex 特有的 **904L 鋼**（含有較高的 Ni, Cr, Mo 和 Cu）與普通 **316L 鋼**。
        
    - **貴金屬驗證：** 確認 "18K Gold" 是否真的含有 75% 的 Au，或者只是鍍金（檢測表面與底層差異）。
        
    - **鈦金屬分級：** 區分 Grade 2 純鈦與 Grade 5 鈦合金。
        

這套系統與你的相機系統是互補的：**相機看外觀特徵（Visual Features），這套代碼看材質成分（Chemical Composition），共同構成完整的真偽鑑定系統。**





#### 3. 表面紋理指紋識別系統 (Surface Texture Fingerprinting)

這組代碼展示了一個非常高階的**表面紋理指紋識別系統 (Surface Texture Fingerprinting)**。

與傳統的「辨識這是什麼零件」（例如：這是錶針、這是錶冠）不同，這套代碼的核心目標是**「量化微觀特徵」**。它試圖讀取金屬表面的「紋理 DNA」，例如 Rolex 錶帶拉絲的間距、噴砂面（Sandblast）的顆粒密度，或是金屬表面獨一無二的微小瑕疵分佈。這通常用於**真偽鑑定**（原廠工藝 vs. 後加工打磨）或是**唯一性識別**（這隻錶是不是上次那一隻）。

以下是詳細的原理與代碼分析：

### 1. 核心技術原理

這套系統使用了幾個關鍵的計算機視覺（Computer Vision）算法：

1. **KAZE 特徵點檢測 (KAZE Features):** 代碼中頻繁出現 `detectKAZEFeatures`。KAZE 是一種比傳統 SIFT 或 SURF 更先進的特徵檢測算法。它使用**非線性擴散濾波**來構建尺度空間。
    
    - **為什麼選 KAZE？** 對於手錶這種金屬表面，KAZE 能在模糊細節的同時保留邊緣（Edge-preserving），這對於捕捉金屬拉絲或噴砂顆粒非常有效，比 SIFT 更能抵抗噪聲。
        
2. **德勞內三角剖分 (Delaunay Triangulation):** 在 `watch_bump_spacing.m` 中，系統將檢測到的特徵點連成三角形網格。
    
    - **目的：** 將散亂的「點」轉化為「幾何結構」。通過計算這些三角形的邊長和面積，系統可以統計出紋理的**均勻度**和**密度**。原廠的表面處理通常有非常特定的統計特徵（例如某種間距的峰值）。
        
3. **熵濾波 (Entropy Filtering) 與 自動對焦檢測:** 在 `Prov_edgepeaks.m` 中使用了 `entropyfilt`。
    
    - **原理：** 圖像中清晰（對焦準確）的區域，其像素值變化大，信息熵（Entropy）高；模糊區域熵低。系統利用這一點自動找出圖像中「清晰的部分」進行分析，忽略模糊背景。
        

---

### 2. 詳細代碼介紹

#### (1) `Prov_edgepeaks.m` (表面顆粒密度分析)

這段代碼專門用來分析表面材質的「粗糙度」或「顆粒感」（例如 Rolex 錶扣內側的噴砂面）。

- **流程：**
    
    1. **亮度提取：** 將圖片轉為 HSV 空間並取 V (Brightness) 通道。
        
    2. **特徵點抓取：** 使用 KAZE 抓取亮點（Bumps）。
        
    3. **去重 (De-duplication)：** 代碼包含一個 `while` 循環和距離判斷，如果兩個點靠太近（小於 `nearrange=2.5` 像素），則視為同一個點，剔除多餘的。這是為了防止對同一個顆粒重複計數。
        
    4. **智能遮罩 (Smart Masking)：**
        
        - 利用 `entropyfilt` 找出「對焦清晰」的區域。
            
        - 利用 `imbinarize` 找出「足夠亮」的區域。
            
        - 取交集 (`and`)，只分析那些**既清晰又足夠亮**的區域。
            
    5. **密度計算：**
        
        - 計算有效區域面積 (mm²)。
            
        - 計算 `bumpspermm` (每平方毫米的顆粒數)。
            
- **應用：** 這是鑑定的黃金標準。例如，正品 Rolex 的噴砂密度可能是 150 bumps/mm，而假貨可能只有 100 或 200。
    

#### (2) `Prov_fingimg.m` (生成手錶指紋)

這個函數為手錶的某個部位建立一個獨一無二的檔案（Fingerprint）。

- **雙重特徵提取：**
    
    - **表面特徵：** 直接在灰階圖上跑 KAZE，抓取表面的微小凹痕或污點。
        
    - **邊緣特徵：** 先用 `edge(...,'Canny')` 找出金屬邊緣線，再在邊緣線上跑 KAZE。這能捕捉到倒角（Chamfering）或邊緣磕碰的特徵。
        
- **視覺化：** 代碼中包含大量的 `plot` 和 `imshow`，會將特徵點（紅星）疊加在原圖或邊緣圖上，方便人工核查。
    
- **存檔：** 將所有特徵點 (Location, Scale, Metric) 存入 `.mat` 檔。日後同一隻錶回來，只要比對這些特徵點是否吻合，就能確認身分。
    

#### (3) `watch_bump_spacing.m` (紋理規律性分析)

這是數學上最有趣的部分。它不再看單個點，而是看點與點之間的**關係**。

- **幾何化：** `DT = delaunayTriangulation([x1,y1])`。將所有顆粒連成三角形。
    
- **統計分析：**
    
    - **邊長 (`dists`):** 顆粒之間的平均距離。
        
    - **面積 (`triareas`):** 三個顆粒圍成的區域大小。
        
    - **形狀因子 (`stretchratio`):** 三角形是否接近正三角形？這反映了顆粒分佈是否均勻。
        
- **直方圖峰值 (`findpeaks`):**
    
    - 代碼繪製了邊長和面積的直方圖，並尋找峰值。
        
    - **意義：** 如果是機器加工的規則紋理（如日內瓦波紋或拉絲），直方圖會有明顯的尖峰（Peak），代表大部顆粒間距是一致的。如果是隨機的手工打磨或磨損，分佈會很寬。
        

#### (4) `watch_bumpsloc.m` (點位過濾邏輯)

這是一段實驗性或中間過程的代碼，主要專注於**空間濾波**。

- 它構建了一個距離矩陣 (`mat3`) 來找出所有距離小於 2.5 像素的點對。
    
- 通過迭代邏輯，保留最強的那個點，刪除周圍的雜點。這確保了後續進行三角剖分時，不會因為噪聲產生極小的、無意義的三角形。
    

#### (5) `watch_micro_fing.m` & `2` (微距特徵提取)

這是 `Prov_fingimg` 的簡化版，專門針對 **Micro (顯微/高倍率)** 圖像。

- 參數 `kazeval1=0.0025` 閾值設得很低，意味著它非常敏感，試圖捕捉極其微小的細節。
    
- 這通常用於分析機芯零件或錶盤字體油墨的邊緣鋸齒。
    

---

### 總結

這套代碼構成了一個**「基於紋理統計的鑑識系統」**。

- **Input:** 相機拍攝的高解析度、不同部位的局部照片。
    
- **Process:**
    
    1. 用 **KAZE** 抓取微觀特徵點。
        
    2. 用 **Entropy** 確保只分析清晰區域。
        
    3. 用 **Delaunay Triangulation** 分析這些點的排列規律（間距、密度）。
        
- **Output:** `bumpspermm` (密度) 和 `LOCSdist` (間距峰值)。
    

**這可以用來回答：**

1. **工藝一致性：** 「這個錶扣的拉絲間距是 0.05mm，符合 Rolex 工廠標準。」
    
2. **真偽識別：** 「這個字體的油墨邊緣特徵點過於平滑（印刷方式不同），判定為非原廠。」
    
3. **個體識別：** 「這隻錶在座標 (x,y) 有一個微小的劃痕特徵，確認是編號 #12345 的那隻錶。」




#### 4. 自動光學檢測 (AOI) 系統

這是一套高度整合的 **自動光學檢測 (AOI) 系統** 的底層控制代碼。

根據這些代碼，你的系統架構包含：

1. **多相機系統**：至少有 4 支相機（Tele, Micro, Top, Side）。
    
2. **精密運動平台**：使用 Zaber 控制器進行 X, Y, Z 三軸移動。
    
3. **雷射/位移感測器**：用於測量表面高度和玻璃厚度。
    
4. **可控光源**：多通道燈光控制。
    

這套系統的核心邏輯是：**「先用大範圍相機定位 -> 移動到目標位置 -> 利用感測器進行精密對焦（需補償玻璃折射） -> 自動調整曝光與增益 -> 拍攝 HDR 影像 -> 用於特徵分析。」**

以下是各模組的詳細原理與代碼解說：

---

### 1. 影像擷取與增強模組 (Image Capture & HDR)

由於手錶金屬表面反光極強（高光溢出），而錶盤深色區域又很暗，普通拍攝無法看清細節。

#### `(watch_cap.m)` - HDR 影像拍攝

- **原理：** 高動態範圍成像 (HDR)。它對同一個場景拍攝多張不同曝光時間 (`exptimes`) 的照片，然後合成一張亮部不曝光、暗部有細節的完美照片。
    
- **代碼解讀：**
    
    - **相機選擇：** 根據 `camID` 映射到硬體 ID (如 `gentl`, 6)。
        
    - **HDR 循環：** `for i=1:length(exptimes)` 迴圈拍攝不同亮度的照片。
        
    - **合成：** 最後使用 `makehdr` 和 `localtonemap` 將多張照片合成並進行色調映射 (Tone Mapping)，壓縮光比。
        
    - **對比度增強：** 包含 `adapthisteq` (自適應直方圖均衡化)，用於增強局部紋理對比。
        

#### `(watch_gain_adjust4.m)` - 自動增益/曝光控制

- **原理：** 類似相機的 "Auto Mode"。不同顏色的錶盤（黑面 vs 白面 Rolex）反射率不同，固定參數會導致過曝或欠曝。
    
- **代碼解讀：**
    
    - **回饋控制迴圈 (Feedback Loop)：** 拍攝一張 -> 計算中心區域亮度 (`mean2`) -> 與目標亮度 (`targetlight=115`) 比較。
        
    - **修正：** 如果太暗，增加 `gainlevel`；如果太亮，降低 `gainlevel`。
        
    - **特徵點檢查：** 如果亮度對了但特徵點 (`pointsfound`) 太少，代表影像模糊或品質不佳，會嘗試再次調整。
        

---

### 2. 運動控制與自動對焦模組 (Motion & Autofocus)

這是系統最複雜的物理控制部分，核心在於**「如何穿過玻璃準確對焦到錶盤」**。

#### `(watch_findsurface.m)` 系列 - 尋找焦平面

- **原理：** 相機景深很淺（尤其是 Micro 鏡頭），必須精確將鏡頭移到焦距位置。
    
- **`watch_findsurface.m` (基礎版)：** 移動到基準高度 `Zbase`，讀取感測器距離，計算目標高度 `Znew`。
    
- **`watch_findsurface2.m` (搜索式對焦 - Micro鏡頭用)：**
    
    - **多層搜索：** 因為手錶厚度不一，如果 `Zbase1` (48mm) 測不到物體（超出感測器量程），它會自動下降到 `Zbase2` (40mm), `Zbase3`... 直到找到物體。
        
    - **玻璃折射補償 (關鍵)：** 代碼中有：`Znew = Zbase + Zdisp - sensordist + glasscorrect;`
        
        - `glasscorrect = (glassthick1 - glassbase) * glassmod;`
            
        - **物理意義：** 光線穿過玻璃會產生折射，導致光學距離與物理距離不同。如果系統偵測到有玻璃 (`hasglass==1`)，它會根據玻璃厚度修正 Z 軸移動量，確保相機是對焦在「玻璃下的錶盤」而不是「玻璃表面」。
            

#### `(watch_glass_thickness.m)` - 測量玻璃厚度

- **原理：** 為了上述的補償，系統需要先知道玻璃有多厚。
    
- **代碼解讀：**
    
    - 在手錶上選定三個點（構成一個小三角形）。
        
    - 在每個點上下移動 Z 軸 (`while` 迴圈)，直到感測器讀到訊號。
        
    - 利用 `watch_sensordistance2` (來自上一個問題的 OUT2) 獲取厚度，最後取平均值 (`mean`)。
        

#### `(watch_findsurface_direct.m)`

- **原理：** 快速尋找表面，不進行複雜的位移計算，主要用於建立初始的安全高度，防止鏡頭撞擊手錶。
    

---

### 3. 工作流程腳本 (Workflow Scripts)

這些腳本將上述功能串聯起來，是使用者實際執行的功能。

#### `(watch_detail_point_collect_double.m)` - 雙重採集流程

- **功能：** 用戶在畫面上點一下，機器自動去拍高解析照。
    
- **流程：**
    
    1. **UI 交互：** 顯示 `telecap` (廣角圖)，使用者用滑鼠點選 (`drawpoint`)。
        
    2. **坐標轉換：** `watch_tele2detail` 將像素坐標 (Pixel) 轉換為機械坐標 (mm)。
        
    3. **安全檢查：** 檢查目標是否超出機械行程 (如 `detailx > 109`)。
        
    4. **移動與對焦：** 呼叫 Zaber 移動 X/Y，呼叫 `watch_findsurface3` 對焦 Z。
        
    5. **燈光與拍攝：** 關閉環形燈，打開頂燈 (`lightnum=4`)，拍攝 HDR 照片。
        

#### `(watch_micro_detail_point_collect_triple2.m)` - 三重採集流程

- **功能：** 用於採集極高維度的數據。
    
- **特色：** 對同一個點，它會改變相機曝光和燈光，連續採集三組數據：
    
    1. **Detail:** 標準細節圖。
        
    2. **Bumps:** 用於分析表面顆粒（如噴砂面），使用高對比度設置。
        
    3. **Light Variation:** 切換燈光方向，用於檢測刮痕或紋理深度。
        

#### `(watch_distance_point_collect.m)` - 兩點測距

- **功能：** 測量手錶上兩個特徵點的高度差或距離。
    
- **邏輯：** 用戶點選兩點 -> 機器依序移動並測量 Z 軸高度 -> 計算差值。這可以用來測量指針與錶盤的間距，或是立體時標的高度。
    

---

### 4. 輔助與分析模組 (Helper & Analysis)

#### `(watch_watchshift_tele2.m)` - 視覺定位校正 (Alignment)

- **問題：** 每次放手錶的位置不可能完全一樣，可能有幾毫米的偏差或旋轉。
    
- **原理：** 影像配準 (Image Registration)。
    
- **代碼解讀：**
    
    1. **特徵提取：** 對當前影像 (`telecap`) 和參考影像 (`reftele`) 提取指紋特徵 (`watch_tele_fing`)。
        
    2. **特徵匹配：** `matchFeatures` 找出兩張圖相同的點。
        
    3. **計算偏移：** 計算匹配點之間的距離差，得出平移向量 (`watchshift`) 和旋轉角度 (`vectangmean`)。
        
    4. **作用：** 系統會利用這個偏移量去修正後續所有 X, Y 的移動指令，確保「點哪裡就拍哪裡」，即使手錶放歪了也能自動修正。
        

#### `(watch_name256.m)`

- **功能：** 產生隨機 ID (Hex String)，用於為每次檢測建立唯一檔案名。
    

---

### 總結系統運作邏輯

1. **Watch Shift:** 系統先拍一張廣角，透過 `watch_watchshift_tele2` 算出與標準位置的偏差。
    
2. **Point Collect:** 使用者在軟體上點擊想要檢查的部位（如：Rolex 的皇冠 Logo）。
    
3. **Motion:** 系統加上偏差值，指揮 Zaber 平台移動到該位置。
    
4. **Auto Focus:**
    
    - 雷射感測器啟動。
        
    - `watch_findsurface` 掃描高度。
        
    - `watch_glass_thickness` 確認有無玻璃。
        
    - 計算出補償後的 Z 軸位置，移動 Micro 相機到位。
        
5. **Capture:**
    
    - `watch_gain_adjust4` 確保亮度正確。
        
    - `watch_cap` 拍攝多張合成 HDR。
        
6. **Data:** 獲得清晰、無反光、對焦精準的微距特徵圖，供後續辨識真偽使用。
