avoided this by giving all the system devices static IPs like:<br>192.168.1.x<br>But the Vanta cannot set a static IP in its UI, so it cannot join that network.<br><br><br>---><br>The safest solution the manually assigned IPs your engineer configured.<br>Your static devices stay exactly the same.<br>Why this is safe<br>Your network currently looks like:<br>192.168.1.10   server<br>192.168.1.20   device<br>192.168.1.30   device<br>We add DHCP for:<br>192.168.1.200–210<br>Those ranges never overlap, so nothing changes for existing equipment.<br><br><br>---><br>The easiest way to do this on Windows<br>Use Internet Connection Sharing (ICS) on the server.<br>Step-by-step<br>Press Windows + R<br>ncpa.cpl<br>Right-click the Wi-Fi adapter (the one connected to the outside network)<br>Click
