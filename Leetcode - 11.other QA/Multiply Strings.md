
字串相乘 Multiply Strings

LeetCode 43 / LintCode 656 給定兩個以字串形式表示的非負整數 `num1` 和 `num2`，請計算這兩個數字的乘積，並同樣以字串形式回傳結果。**限制條件：** 不能使用任何內建的大數處理函式庫，也不能直接將整個輸入字串轉型為整數來進行乘法運算。

**样例 1：** 输入：
```Python
num1 = "2"
num2 = "3"
```

输出：
```Python
"6"
```

解释： 2 乘以 3 等於 6，轉為字串 "6"

**样例 2：** 输入：
```Python
num1 = "123"
num2 = "456"
```

输出：
```Python
"56088"
```

解释： 123 × 456 = 56088

**样例 3：** 输入：
```Python
num1 = "9133"
num2 = "0"
```

输出：
```Python
"0"
```

解释： 任何數乘以 "0" 結果皆為 "0"（注意不能回傳多個前導零如 "0000"）

```Python
class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if num1 == "0" or num2 == "0":
            return "0"

        m, n = len(num1), len(num2)
        res = [0] * (m + n)

        # 從低位（右邊）往高位（左邊）模擬直式乘法
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                mul = (ord(num1[i]) - ord('0')) * (ord(num2[j]) - ord('0'))
                p1, p2 = i + j, i + j + 1

                # 加上原本在 p2 位置的進位值
                total = mul + res[p2]

                res[p2] = total % 10      # 當前位保留個位數
                res[p1] += total // 10    # 十位數往前一位進位

        # 跳過開頭多餘的 0，將陣列轉為字串
        start = 0
        while start < len(res) and res[start] == 0:
            start += 1

        return "".join(map(str, res[start:]))
```


```Python
class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if "0" in [num1, num2]:
            return "0"

        res = [0] * (len(num1) + len(num2))
        num1, num2 = num1[::-1], num2[::-1]

        # 反轉字串後，索引 0 即為個位數，i + j 直接對應結果的位數權重
        for i1 in range(len(num1)):
            for i2 in range(len(num2)):
                digit = int(num1[i1]) * int(num2[i2])
                res[i1 + i2] += digit
                res[i1 + i2 + 1] += res[i1 + i2] // 10
                res[i1 + i2] = res[i1 + i2] % 10

        # 反轉回來並去除前導零
        res, beg = res[::-1], 0
        while beg < len(res) and res[beg] == 0:
            beg += 1

        res = map(str, res[beg:])
        return "".join(res)
```

解釋: step1: 若 `num1` 或 `num2` 其中一個為 `"0"`，直接回傳 `"0"`，避免後續還要處理全零陣列的邊界 step2: 長度為 `m` 與 `n` 的兩個整數相乘，乘積的總位數**最多為 `m + n` 位**（例如 `99 * 99 = 9801`，`2 + 2 = 4` 位），因此初始化長度 `m + n` 的陣列 `res` 全部填 `0` step3: 雙層迴圈從個位數往高位遍歷，`num1[i]` 與 `num2[j]` 相乘的結果會精準落在 `res` 的 `i + j`（十位進位）與 `i + j + 1`（個位）這兩個索引上 step4: 假設 `num1 = "12"`, `num2 = "34"`（`res = [0, 0, 0, 0]`）：

- `i=1 ('2'), j=1 ('4')`：`mul = 8`，`p1=2, p2=3` -> `res = [0, 0, 0, 8]`
    
- `i=1 ('2'), j=0 ('3')`：`mul = 6`，`p1=1, p2=2` -> `res = [0, 0, 6, 8]`
    
- `i=0 ('1'), j=1 ('4')`：`mul = 4`，`p1=1, p2=2`，`total = 4 + res[2] = 10` -> `res[2] = 0, res[1] += 1` -> `res = [0, 1, 0, 8]`
    
- `i=0 ('1'), j=0 ('3')`：`mul = 3`，`p1=0, p2=1`，`total = 3 + res[1] = 4` -> `res[1] = 4, res[0] += 0` -> `res = [0, 4, 0, 8]` step5: 跳過索引 `0` 的前導零，將 `[4, 0, 8]` 拼接成 `"408"` 回傳

### **LeetCode 43 / LintCode 656 - Multiply Strings（字串相乘）**

這道題目是 **NeetCode 150（Math & Geometry 分類）** 的高頻經典題，考察如何在不使用內建大數型別的情況下，透過陣列精準控制進位來模擬大數乘法。

## **解法解析**

這道題如果直接模仿直式乘法「先算出一排排中間結果，最後再把所有字串加總」，寫起來會非常繁瑣；透過 **固定長度陣列 + 索引位置映射** 可以大幅簡化邏輯。

### **思路**

1. **確定結果的最大長度**
    
    - 兩個正整數相乘，位數最多不會超過兩者長度之和 `m + n`（最小情況則是 `m + n - 1` 位，例如 `10 * 10 = 100` 是 3 位，開頭會多一個前導 `0`）。
        
    - 因此預先配置 `res = [0] * (m + n)` 一定裝得下所有進位，完全不會產生 Index Out of Bounds。
        
2. **找出乘積與陣列索引的對應關係**
    
    - 觀察 `num1` 的第 `i` 位與 `num2` 的第 `j` 位（由左至右 0-indexed）：
        
    - 它們相乘得到的兩位數（若為個位數則十位補 0），其**十位數**一定落在 `res[i + j]`，**個位數**一定落在 `res[i + j + 1]`。
        
    - 透過從右往左（低位到高位）遍歷，每次計算時只要把 `mul` 加上原本已經存放在 `res[i + j + 1]` 的值，再分別取 `% 10` 與 `// 10` 更新 `p2` 與 `p1` 即可。
        
3. **進位暫存的巧思**
    
    - 在處理過程中，`res[p1]` 即使暫時被累加到超過 `10` 也完全沒關係！因為下一輪外層或內層迴圈移動到該位置時，它會作為 `res[p2]` 再次被 `% 10` 和 `// 10` 消化掉，把多餘的進位繼續往左推。
        

## **具體舉例**

假設 `num1 = "25"`, `num2 = "36"`（`m = 2, n = 2`，初始 `res = [0, 0, 0, 0]`），執行過程如下：

|步驟 `(i, j)`|字元相乘 `mul`|目標位置 `(p1, p2)`|加上舊值 `total`|更新後 `res` 狀態|
|---|---|---|---|---|
|初始化|-|-|-|`[0, 0, 0, 0]`|
|`(1, 1)`|`'5' * '6' = 30`|`(2, 3)`|`30 + 0 = 30`|`[0, 0, 3, 0]`|
|`(1, 0)`|`'5' * '3' = 15`|`(1, 2)`|`15 + 3 = 18`|`[0, 1, 8, 0]`|
|`(0, 1)`|`'2' * '6' = 12`|`(1, 2)`|`12 + 8 = 20`|`[0, 3, 0, 0]`|
|`(0, 0)`|`'2' * '3' = 6`|`(0, 1)`|`6 + 3 = 9`|`[0, 9, 0, 0]`|

最後跳過索引 `0` 的前導 `0`，將 `[9, 0, 0]` 轉為字串 `"900"`。

## **時間與空間複雜度分析**

- **時間複雜度：O(m × n)**
    
    - 其中 `m` 和 `n` 分別為 `num1` 和 `num2` 的字串長度。雙層迴圈需要兩兩相乘所有數位，共執行 `m * n` 次常數時間操作；最後去除前導零與拼接字串需要 `O(m + n)`，整體時間複雜度為 **O(m × n)**。
        
- **空間複雜度：O(m + n)**
    
    - 需要一個長度為 `m + n` 的整數陣列 `res` 來儲存每一位的計算結果與進位。
        

## **其他解法**

### **1. 逐位乘積後呼叫「字串相加（Add Strings）」**

- **思路**：
    
    - 將 `num2` 的每一位單獨與整個 `num1` 相乘，得到 `n` 個中間結果字串（記得在尾端補上對應數量的 `'0'`），最後像 LeetCode 415 一樣把它們逐一相加。
        
- **優缺點**：
    
    - 邏輯最符合人類手算直覺，但需要額外實作 `addStrings` 輔助函式，且會反覆建立與銷毀中間字串，常數時間開銷較大。
        
- **時間複雜度**：O(m × n + n²)
    
- **空間複雜度**：O(m + n)
    

### **2. 快速傅立葉變換（FFT / NTT）多項式乘法**

- **思路**：
    
    - 把十進位數字看作 x=10x = 10x=10 的多項式係數，利用 FFT 將多項式乘法從 O(n2)O(n^2)O(n2) 優化到 O(nlog⁡n)O(n \log n)O(nlogn)，最後統一處理進位。
        
- **適用場景**：
    
    - 僅在字串長度極大（例如超過 10510^5105 位）的高精度競賽題才有必要使用；一般技術面試寫到 `O(m × n)` 陣列模擬法即為最優標準解。
        
- **時間複雜度**：O((m + n) log(m + n))
    
- **空間複雜度**：O(m + n)
    

## **總結**

- **面試最推薦解法**：**長度 `m + n` 陣列直式乘法模擬**（正序從尾端遍歷或反轉後從頭遍歷皆可），時間 `O(m × n)`，空間 `O(m + n)`，程式碼簡潔且不易出錯。
    
- **常見易錯點**：
    
    1. 忘記提前處理 `"0"` 的情況，導致例如 `"123" * "0"` 算出 `[0, 0, 0, 0]` 後去除前導零變成空字串 `""`。
        
    2. 混淆 `p1 = i + j`（十位進位）與 `p2 = i + j + 1`（個位）的順序。

### **延伸變形題：LeetCode 415 - Add Strings（字串相加）**

給定兩個以字串形式表示的非負整數 `num1` 和 `num2`，不使用內建大數函式庫或直接轉為整數，計算兩者之和並以字串回傳（常作為字串乘法拆分解法中的核心子函式）。

Python

```
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i, j = len(num1) - 1, len(num2) - 1
        carry = 0
        res = []

        # 只要還有任一字串未遍歷完，或還有殘留進位，就繼續運算
        while i >= 0 or j >= 0 or carry:
            n1 = ord(num1[i]) - ord('0') if i >= 0 else 0
            n2 = ord(num2[j]) - ord('0') if j >= 0 else 0

            total = n1 + n2 + carry
            res.append(str(total % 10))
            carry = total // 10

            i -= 1
            j -= 1

        # 因為是從低位往高位加入陣列，最後需反轉再拼接
        return "".join(res[::-1])
```
