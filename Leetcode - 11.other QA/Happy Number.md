
LeetCode 202 / LintCode 488 編寫一個演算法來判斷一個正整數 `n` 是不是「快樂數」（Happy Number）。

**「快樂數」定義為：**
- 對於一個正整數，每一次將該數替換為它每個位置上的數字的平方和。
- 重複這個過程直到這個數變為 `1`，也可能是 **無限循環** 但始終變不到 `1`。
- 如果這個過程 **結果為 `1`**，那麼這個數就是快樂數。
- 如果 `n` 是快樂數就回傳 `True`；不是，則回傳 `False`。

**样例 1：** 输入：
```Python
n = 19
```

输出：
```Python
True
```

解释： 1^2 + 9^2 = 82 8^2 + 2^2 = 68 6^2 + 8^2 = 100 1^2 + 0^2 + 0^2 = 1 -> 結果為 1，回傳 True

**样例 2：** 输入：
```Python
n = 2
```

输出：
```Python
False
```

解释： 2^2 = 4 -> 16 -> 37 -> 58 -> 89 -> 145 -> 42 -> 20 -> 4 (進入無限循環，永遠無法到達 1)

**样例 3：** 输入：
```Python
n = 1
```

输出：
```Python
True
```

解释： 一開始就等於 1，直接回傳 True
```Python
class Solution:
    def isHappy(self, n: int) -> bool:
        seen = set()
        while n != 1 and n not in seen:
            seen.add(n)
            n = self.get_next(n)
        return n == 1

    def get_next(self, n: int) -> int:
        total_sum = 0
        while n > 0:
            digit = n % 10
            total_sum += digit ** 2
            n //= 10
        return total_sum
```

```Python
class Solution:
    def isHappy(self, n: int) -> bool:
        seen = set()
        while n != 1:
            if n in seen:
                return False
            seen.add(n)
            n = sum(int(digit) ** 2 for digit in str(n))
        return True
```

解釋: step1: 建立一個集合 `seen = set()`，用來記錄所有已經出現過的數字，偵測是否進入無限循環 step2: 當 `n != 1` 時進入 `while` 迴圈 step3: 檢查目前的 `n` 是否已經在 `seen` 裡面。如果在，代表進入循環且永遠不會變成 `1`，直接回傳 `False` step4: 將目前的 `n` 加入 `seen` 中 step5: 拆解 `n` 的每一位數並計算平方和（例如 `n = 19` -> `1^2 + 9^2 = 82`），更新 `n` step6: 若迴圈順利結束（代表 `n == 1`），回傳 `True`

n = 19 -> result = True

1. `seen = {19}` -> `n = 82`
    
2. `seen = {19, 82}` -> `n = 68`
    
3. `seen = {19, 82, 68}` -> `n = 100`
    
4. `seen = {19, 82, 68, 100}` -> `n = 1` (跳出迴圈，回傳 `True`)
    

解釋: 這題的核心在於「偵測循環（Cycle Detection）」。 對於任何正整數，不斷計算各位數平方和，最終只會出現兩種情況：

1. 最終收斂到 `1`。
    
2. 陷入一個不包含 `1` 的循環中（永遠不會無限增大，因為多位數的平方和會迅速縮小）。 因此只要用 Hash Set 記錄走過的數字，一旦重複出現就代表進入循環。
    

### **LeetCode 202 - Happy Number（快樂數）**

這道題目是 Blind 75 與 NeetCode 150 中 **Math & Geometry** 與 **Hash Set / Two Pointers** 的經典題目。核心考點在於如何拆解數字的每一位，以及如何判斷計算過程是否進入了 **無限循環**。

## **解法解析**

這道題可以轉化為 **鏈結串列偵測環（Cycle Detection）** 的問題來求解。

### **思路**

1. **為什麼不會無限增大？**
    
    - 假設有一個 3 位數 `999`，它的下一個數字是 $9^2 + 9^2 + 9^2 = 243$。
        
    - 假設有一個 4 位數 `9999`，它的下一個數字是 $9^2 \times 4 = 324$。
        
    - 這代表任何大於 `243` 的數字，經過幾次轉換後一定會掉到 `243` 以下，因此數字 **不可能無限變大**，只會 **收斂到 1** 或 **在 243 以內產生循環**。
        
2. **使用 Hash Set 記錄軌跡**
    
    - 每次計算出新的數字 `next_n` 之前，先檢查它是否已經存在於 `seen` 集合中。
        
    - 若存在，說明形成了一個環（Cycle），回傳 `False`。
        
    - 若 `n` 變為 `1`，回傳 `True`。
        
3. **數字拆解技巧**
    
    - **數學取餘法（推薦，省空間）**：透過 `n % 10` 取得個位數，`n //= 10` 去掉個位數。
        
    - **字串轉換法（簡潔）**：`sum(int(i) ** 2 for i in str(n))`。
        

## **具體舉例**

### **情況 A：快樂數 (`n = 19`)**

|**步驟**|**當前 n**|**平方和計算過程**|**下一個 n**|**seen 集合狀態**|
|---|---|---|---|---|
|1|`19`|$1^2 + 9^2 = 1 + 81$|`82`|`{19}`|
|2|`82`|$8^2 + 2^2 = 64 + 4$|`68`|`{19, 82}`|
|3|`68`|$6^2 + 8^2 = 36 + 64$|`100`|`{19, 82, 68}`|
|4|`100`|$1^2 + 0^2 + 0^2 = 1$|`1`|`{19, 82, 68, 100}`|

最後 `n == 1` 跳出迴圈，回傳 **`True`**。

### **情況 B：非快樂數 (`n = 2`)**

|**步驟**|**當前 n**|**下一個 n**|**說明**|
|---|---|---|---|
|1|`2`|`4`|記錄 `2`|
|2|`4`|`16`|記錄 `4`（循環起點）|
|3 ~ 8|`16 -> 37 -> 58 -> 89 -> 145 -> 42`|`20`|持續計算並加入 `seen`|
|9|`20`|`4`|`4` 已存在於 `seen` 中，偵測到環！|

偵測到重複數字 `4`，直接回傳 **`False`**。

## **時間與空間複雜度分析**

- **時間複雜度：O(log n)**
    
    - 一個數字 `n` 總共有 $\lfloor \log_{10}(n) \rfloor + 1$ 位數，計算一次各位數平方和的時間為 **O(log n)**。
        
    - 無論 `n` 多大，第一次運算後都會迅速縮小到常數級別（小於 243），後續在循環中最多執行常數次（最多 243 步），因此總時間複雜度為 **O(log n)**。
        
- **空間複雜度：O(log n)**（若使用快慢指標則為 **O(1)**）
    
    - 使用 Hash Set 儲存出現過的數字，在最壞情況下需要儲存的數字數量與 `log n` 成正比（大於 243 後最多再存常數個數字），因此空間複雜度為 **O(log n)**。
        

## **其他解法**

### **1. 快慢指標法（Floyd's Cycle-Finding Algorithm） - O(1) 空間優化**

- **思路**：
    
    - 把數字的轉換過程看作一個隱式的 **單向鏈結串列（Linked List）**。
        
    - 設定 `slow` 每次走 1 步（計算 1 次平方和），`fast` 每次走 2 步（計算 2 次平方和）。
        
    - 如果有環，`fast` 一定會在環內追上 `slow`（`slow == fast`）；如果沒有環，`fast` 會先到達 `1`。
        
- **時間複雜度**：O(log n)
    
- **空間複雜度**：**O(1)**（不需要額外的 `set`）
    

### **2. 數學硬編碼法（Hardcoding the Only Cycle）**

- **思路**：
    
    - 數學上已證明，所有非快樂數最終都會掉進唯一的一個循環：`4 -> 16 -> 37 -> 58 -> 89 -> 145 -> 42 -> 20 -> 4`。
        
    - 只要在迴圈中判斷 `n != 1 and n != 4`，若變成 `4` 就直接回傳 `False`。
        
- **時間複雜度**：O(log n)
    
- **空間複雜度**：**O(1)**
    

## **總結**

- **面試最直觀解法**：使用 **Hash Set (`seen`)** 記錄走過的數字，邏輯清晰、不易寫錯，時間 `O(log n)`，空間 `O(log n)`。
    
- **面試進階最佳解（Follow-up 要求 O(1) 空間）**：使用 **快慢指標（Floyd 判圈演算法）**，不需要額外記憶體空間，且能展現對 Linked List 偵測環觀念的融會貫通。

### **進階延伸：O(1) 空間複雜度解法（快慢指標完整代碼）**

如果面試官要求：「**不允許使用額外的 Hash Set（要求空間複雜度為 O(1)），該怎麼解？**」

Python

```
class Solution:
    def isHappy(self, n: int) -> bool:
        def get_next(number: int) -> int:
            total_sum = 0
            while number > 0:
                number, digit = divmod(number, 10) # 同時取得商數與餘數
                total_sum += digit ** 2
            return total_sum

        slow = n
        fast = get_next(n)
        
        # 當 fast 還沒到達 1，且快慢指標還沒相遇時持續前進
        while fast != 1 and slow != fast:
            slow = get_next(slow)             # 慢指標每次走 1 步
            fast = get_next(get_next(fast))   # 快指標每次走 2 步
            
        # 若 fast 抵達 1 代表是快樂數；若 slow == fast 則代表遇到循環
        return fast == 1
```
