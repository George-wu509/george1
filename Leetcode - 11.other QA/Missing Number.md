
eetCode 268 / LintCode 196 給定一個包含 `[0, n]` 中 `n` 個不重複整數的陣列 `nums`，請找出 `[0, n]` 這個範圍內沒有出現在陣列中的那個數。

**進階要求（Follow-up）：**

- 你能否僅使用 **O(1) 額外空間複雜度** 和 **O(n) 時間複雜度** 來解決此問題？
    

**样例 1：** 输入：
```Python
nums = [3, 0, 1]
```

输出：
```Python
2
```

解释： n = 3，因為陣列中有 3 個數字，所以所有數字都在範圍 [0, 3] 內。 完整集合應為 [0, 1, 2, 3]，其中 2 沒有出現在 nums 中。

**样例 2：** 输入：
```Python
nums = [0, 1]
```

输出：
```Python
2
```

解释： n = 2，完整範圍為 [0, 2]，2 是缺失的數字。

**样例 3：** 输入：
```Python
nums = [9, 6, 4, 2, 3, 5, 7, 0, 1]
```

输出：
```Python
8
```

解释： n = 9，完整範圍為 [0, 9]，8 是缺失的數字。
```Python
class Solution:
    def missingNumber(self, nums: list[int]) -> int:
        n = len(nums)
        expected_sum = n * (n + 1) // 2
        actual_sum = sum(nums)
        return expected_sum - actual_sum
```


```Python
class Solution:
    def missingNumber(self, nums: list[int]) -> int:
        res = len(nums)
        for i, num in enumerate(nums):
            res ^= i ^ num
        return res
```

解釋: step1: 取得陣列長度 `n = len(nums)`，代表原本應該包含 `0` 到 `n` 共 `n + 1` 個數字 step2: 初始化 `res = n`（先把最後一個索引 `n` 放入 XOR 累積器中，因為迴圈索引 `i` 只會跑到 `n - 1`） step3: 遍歷陣列 `nums`，同時取得索引 `i` 與數值 `num` step4: 每次執行 `res ^= i ^ num`（利用 XOR 的性質：$a \oplus a = 0$ 且 $a \oplus 0 = a$） step5: 所有出現過的數字都會和對應的索引 `0 ~ n` 兩兩抵消成 `0` step6: 迴圈結束後，`res` 剩下的唯一數字就是沒有被抵消掉的「缺失數字」，直接回傳 `res`

nums = [3, 0, 1] -> result = 2

1. 初始 `res = 3`
    
2. `i = 0, num = 3` -> `res = 3 ^ 0 ^ 3 = 0`
    
3. `i = 1, num = 0` -> `res = 0 ^ 1 ^ 0 = 1`
    
4. `i = 2, num = 1` -> `res = 1 ^ 2 ^ 1 = 2` (回傳 `2`)
    

解釋: 這題有兩種最經典的 **O(n) 時間、O(1) 空間** 解法：

1. **高斯求和公式（Math）**：計算 `0` 到 `n` 的理論總和 $\frac{n(n+1)}{2}$，減去陣列實際總和 `sum(nums)`，差值即為缺失的數字。
    
2. **位元運算（Bit Manipulation - XOR）**：將完整的索引 `0 ~ n` 與陣列內所有元素全部做 XOR 運算，成對出現的數字會自動抵消為 `0`，最後留下的就是缺失的那個數字。
    

### **LeetCode 268 - Missing Number（缺失的數字）**

這道題目是 Blind 75 與 NeetCode 150 中 **Bit Manipulation（位元運算）** 與 **Math & Geometry** 的基礎必考題。雖然用 Hash Set 或排序也能輕鬆解出，但面試官通常會要求 **O(1) 額外空間** 的最佳解。

## **解法解析**

這道題的核心概念是 **「完整集合與實際集合的差異比較」**。

### **思路**

1. **高斯等差級數求和法（Math）**
    
    - 如果沒有缺任何數字，陣列應該包含 `0, 1, 2, ..., n`。
        
    - 根據等差級數公式，這 `n + 1` 個數字的理論總和為：
        
        $$\text{expected\_sum} = \frac{n \times (n + 1)}{2}$$
        
    - 將理論總和減去陣列實際元素總和 `sum(nums)`，多出來的部分就是被拿走的那個數字。
        
2. **位元互斥或運算（Bitwise XOR）**
    
    - XOR 運算具備三個關鍵特性：
        
        - **歸零律**：$a \oplus a = 0$
            
        - **恆等律**：$a \oplus 0 = a$
            
        - **交換律與結合律**：$a \oplus b \oplus a = (a \oplus a) \oplus b = 0 \oplus b = b$
            
    - 我們將 **索引 `0` 到 `n`** 視為一組完整數字，**陣列元素 `nums[0]` 到 `nums[n-1]`** 視為另一組數字。把這兩組數字全部 XOR 在一起，出現兩次的數字會互相抵消，唯獨缺失的數字只出現一次，會被完整保留下來。
        
3. **防止溢位的小細節**
    
    - 在 C++ 或 Java 等靜態型別語言中，若 `n` 非常大（例如 $n = 10^5$），計算 `n * (n + 1)` 可能會導致 **整數溢位（Integer Overflow）**。
        
    - 使用 **XOR 解法** 或 **邊加邊減法**（`res += i - nums[i]`）可以完全避免溢位風險。
        

## **具體舉例**

### **方法一：位元運算 XOR (`nums = [3, 0, 1]`)**

初始狀態：`n = 3`，設定 `res = 3`

|**步驟 (i)**|**索引 i**|**元素 nums[i]**|**運算式 (res ^= i ^ nums[i])**|**當前 res**|**抵消說明**|
|---|---|---|---|---|---|
|初始|-|-|`res = 3`|`3`|先放入 `n = 3`|
|`i = 0`|`0`|`3`|`3 ^ 0 ^ 3`|`0`|`3` 與 `3` 抵消|
|`i = 1`|`1`|`0`|`0 ^ 1 ^ 0`|`1`|`0` 與 `0` 抵消|
|`i = 2`|`2`|`1`|`1 ^ 2 ^ 1`|`2`|`1` 與 `1` 抵消，留下 `2`|

最終回傳 **`2`**。

### **方法二：高斯求和公式 (`nums = [3, 0, 1]`)**

|**項目**|**計算公式**|**數值**|
|---|---|---|
|陣列長度 `n`|`len([3, 0, 1])`|`3`|
|理論總和 (`expected_sum`)|`3 * (3 + 1) // 2`|`6`|
|實際總和 (`actual_sum`)|`3 + 0 + 1`|`4`|
|缺失數字|`6 - 4`|**`2`**|

## **時間與空間複雜度分析**

- **時間複雜度：O(n)**
    
    - 無論是計算 `sum(nums)` 或是單次迴圈執行 `XOR` 運算，都只需要線性掃描陣列一次，因此時間複雜度為 **O(n)**。
        
- **空間複雜度：O(1)**
    
    - 只需要常數個變數（`res` 或 `expected_sum`、`actual_sum`）來儲存中間計算結果，不需要額外配置陣列或雜湊表，空間複雜度為 **O(1)**。
        

## **其他解法**

### **1. 雜湊集合法（Hash Set）**

- **思路**：
    
    - 將 `nums` 轉換為 `set(nums)`，接著用 `for i in range(n + 1)` 逐一檢查 `i` 是否不在集合中。
        
- **時間複雜度**：O(n)
    
- **空間複雜度**：**O(n)**（需要額外儲存 `n` 個元素的集合）
    

### **2. 排序後比對索引法（Sorting）**

- **思路**：
    
    - 先將 `nums` 由小到大排序（`nums.sort()`），正常情況下每個位置應該滿足 `nums[i] == i`。
        
    - 從頭遍歷，第一個發現 `nums[i] != i` 的索引 `i` 就是缺失的數字；若全部都符合，則缺失的是 `n`。
        
- **時間複雜度**：**O(n log n)**（排序所需的時間）
    
- **空間複雜度**：O(1) 或 O(n)（取決於語言內建排序演算法的空間開銷）
    

## **總結**

- **最簡潔直觀解法**：**高斯求和公式**（`n * (n + 1) // 2 - sum(nums)`），程式碼最短、可讀性最高，時間 `O(n)`，空間 `O(1)`。
    
- **面試官最愛進階解**：**位元運算 XOR**，同樣為時間 `O(n)`、空間 `O(1)`，且在任何程式語言中都不會有整數溢位（Overflow）問題。

### **進階延伸：如果輸入的陣列「已經排序」怎麼辦？**

如果面試官將題目條件修改為：「**假設給定的陣列 `nums` 已經是升序排列（Sorted），你能否在 O(log n) 時間內找到缺失的數字？**」

Python

```
class Solution:
    def missingNumberSorted(self, nums: list[int]) -> int:
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            # 若 nums[mid] == mid，代表左半邊完全沒有缺數字，缺失值一定在右半邊
            if nums[mid] == mid:
                left = mid + 1
            # 若 nums[mid] > mid，代表左半邊已經發生錯位（缺了數字），往左半邊縮小範圍
            else:
                right = mid - 1
                
        # 迴圈結束時，left 指標會精準停在第一個「值與索引不符」的位置，即為缺失的數字
        return left
```
