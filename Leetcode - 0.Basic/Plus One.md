
LeetCode 66 / LintCode 407 给定一个由 **整数** 组成的 **非空** 数组所表示的非负整数，在该数的基础上加一。最高位数字存放在数组的首位， 数组中每个元素只存储 **单个** 数字。你可以假设除了整数 0 之外，这个整数不会以零开头。

**样例 1：** 输入：
```Python
digits = [1, 2, 3]
```

输出：
```Python
[1, 2, 4]
```

解释： 输入数组表示数字 123，加一后得到 124。

**样例 2：** 输入：
```Python
digits = [1, 2, 9]
```

输出：
```Python
[1, 3, 0]
```

解释： 输入数组表示数字 129，个位 9 加一产生进位变成 0，十位 2 加上进位变成 3，得到 130。

**样例 3：** 输入：
```Python
digits = [9, 9]
```

输出：
```Python
[1, 0, 0]
```

解释： 输入数组表示数字 99，所有位数都为 9，连续进位后最高位需要新增一位 `1`，得到 100。

```Python
# 解法一：從後往前遍歷（原地修改，最優解）
def plusOne(self, digits: list[int]) -> list[int]:
    for i in range(len(digits) - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits
        digits[i] = 0
    return [1] + digits
```


```Python
# 解法二：模擬進位 Carry（NeetCode 經典反轉陣列寫法）
def plusOne(self, digits: list[int]) -> list[int]:
    digits = digits[::-1]
    carry, i = 1, 0
    while carry:
        if i < len(digits):
            if digits[i] == 9:
                digits[i] = 0
            else:
                digits[i] += 1
                carry = 0
        else:
            digits.append(1)
            carry = 0
        i += 1
    return digits[::-1]
```

解釋（以解法一為例）: step1: 從陣列的最後一位（最低位）往前遍歷，以 `digits = [1, 2, 9]` 為例，索引範圍為 `2 -> 1 -> 0` step2: `i = 2`，`digits[2]` 是 `9`（不小於 9），代表加一會產生進位，因此將 `digits[2]` 設為 `0`，目前陣列為 `[1, 2, 0]` step3: `i = 1`，`digits[1]` 是 `2`（小於 9），代表進位到這裡就停止了，直接將 `digits[1] += 1` 變成 `3` step4: 因為前面高位不會再受影響，直接 `return digits`，回傳 `[1, 3, 0]` step5: 若整個迴圈跑完都沒回傳（例如 `[9, 9]`），代表所有位數都變成了 `0`，最後在最前面補上 `[1]`，回傳 `[1] + digits` 即 `[1, 0, 0]`

解釋（以解法二為例）: 先將陣列反轉，讓低位在索引 `0`、高位在後，並將初始進位 `carry` 設為 `1`。只要還有進位就繼續處理：遇到 `9` 就歸零並繼續進位；遇到非 `9` 就加 `1` 並把 `carry` 歸零；若超出原本長度則直接 `append(1)`，最後再把陣列反轉回來。

### **LeetCode 66 / LintCode 407 - Plus One（加一）**

這道題目是 NeetCode 150 中 **Math & Geometry（數學與幾何）** 分類的基礎代表題。題目看似簡單，但重點在於考察**邊界條件（Edge Cases）的處理能力**，特別是連續進位（如 `999 -> 1000`）時陣列長度需要擴張的情況。

## **解法解析**

這道題的核心在於觀察「加法進位」的特性：**只有在遇到 `9` 的時候才會繼續往左進位，一旦遇到任何小於 `9` 的數字，進位就會立刻終止**。

### **思路**

1. **觀察規律（三種情況）**
    
    - **情況一：末位不是 `9`**（例如 `[1, 2, 3]`）
        
        - 只需要把最後一位加 `1`，前面所有數字完全不變，直接回傳 `[1, 2, 4]`。
            
    - **情況二：末位有連續的 `9`，但不是全部都是 `9`**（例如 `[1, 9, 9]`）
        
        - 從右往左掃描，遇到的 `9` 全部變成 `0`，直到遇到第一個不是 `9` 的數字（索引 `0` 的 `1`），將它加 `1` 變成 `2`，進位結束，回傳 `[2, 0, 0]`。
            
    - **情況三：所有位數全都是 `9`**（例如 `[9, 9, 9]`）
        
        - 從右往左掃描完所有元素後，陣列會變成 `[0, 0, 0]`，迴圈正常結束。此時代表最高位產生了溢位進位，只需要在陣列最前方拼接一個 `1`，回傳 `[1, 0, 0, 0]`。
            
2. **發現核心判斷邏輯**
    
    - 倒序遍歷索引 `i` 從 `len(digits) - 1` 到 `0`：
        
    - 若 `digits[i] < 9`：執行 `digits[i] += 1` 並 **立即 `return digits`**（Early Return）。
        
    - 若 `digits[i] == 9`：執行 `digits[i] = 0`，讓迴圈繼續處理前一位。
        
    - 迴圈結束後仍未回傳：執行 `return [1] + digits`。
        
3. **代碼執行流程**
    
    - 利用 `range(len(digits) - 1, -1, -1)` 從個位數開始檢查。
        
    - 只要不發生進位就提早結束函式，省去多餘的遍歷。
        
    - 只有全為 `9` 的極端情況才會執行到最後一行的陣列拼接。
        

## **具體舉例**

假設 `digits = [9, 9]`（全為 9 的極端情況），變數變化如下：

|`i`|當前 `digits[i]`|判斷 `digits[i] < 9`|操作|更新後 `digits`|狀態說明|
|---|---|---|---|---|---|
|初始化|-|-|-|`[9, 9]`|從最後一位 `i = 1` 開始|
|`i = 1`|`9`|False|`digits[1] = 0`|`[9, 0]`|個位滿 10 歸零，繼續往左進位|
|`i = 0`|`9`|False|`digits[0] = 0`|`[0, 0]`|十位滿 10 歸零，繼續往左進位|
|迴圈結束|-|-|`return [1] + digits`|`[1, 0, 0]`|最高位溢位，前端補 `1`|

最後返回 `[1, 0, 0]`，表示 `99 + 1 = 100`。

## **時間與空間複雜度分析**

- **時間複雜度：O(n)**
    
    - 其中 `n` 是陣列 `digits` 的長度。
        
    - 最佳情況（末位不為 `9`）只需 `O(1)` 時間；最壞情況（全為 `9`）需要遍歷整個陣列並建立新陣列，時間複雜度為 **O(n)**。
        
- **空間複雜度：O(1)**（或 **O(n)**）
    
    - 若不計算回傳結果所佔用的空間，演算法是直接原地修改（In-place）輸入陣列，額外空間複雜度為 **O(1)**。
        
    - 只有在全為 `9` 的最壞情況下，需要配置一個長度為 `n + 1` 的新陣列 `[1] + digits`，此時空間複雜度為 **O(n)**。
        

## **其他解法**

### **1. 型別轉換法（陣列 -> 整數 -> 陣列）**

- **思路**：
    
    - 將陣列中的數字轉成字串拼接成完整整數，加 `1` 後再轉回整數陣列： `[int(x) for x in str(int("".join(map(str, digits))) + 1)]`
        
- **優缺點**：
    
    - 在 Python 中因為支援大數運算（Arbitrary-precision integers）可以一行寫完，但在 C++ / Java 等語言會發生整數溢位（Integer Overflow），且面試官通常希望看到陣列操作而非轉型偷吃步。
        
- **時間複雜度**：O(n)
    
- **空間複雜度**：O(n)
    

### **2. 顯式進位變數法（Carry Variable）**

- **思路**：
    
    - 維護一個變數 `carry = 1`，從後往前遍歷時計算 `total = digits[i] + carry`，更新 `digits[i] = total % 10` 與 `carry = total // 10`。
        
    - 這種寫法的好處是擴充性強，如果題目改成「加 K」而不只是「加 1」，可以直接套用。
        
- **時間複雜度**：O(n)
    
- **空間複雜度**：O(1)
    

## **總結**

- **面試最推薦解法**：**從後往前倒序遍歷 + 遇到 `< 9` 提早返回（Early Return）**，程式碼極簡（僅 6 行）、原地修改且邏輯清晰。
    
- **容易踩的坑**：忘記處理 `[9]` 或 `[9, 9]` 這種**位數增加**的情況，導致回傳 `[0]` 或 `[0, 0]`。
    
- **擴充思維**：若題目改為「加任意整數 `k`」，則適合改用 `total = digits[i] + carry` 的通用進位模板。

### **進階變形：LeetCode 369 - Plus One Linked List（給單向鏈結串列加一）**

如果題目把「陣列」改成「**單向鏈結串列（Singly Linked List）**」（例如 `1 -> 2 -> 9` 變成 `1 -> 3 -> 0`），因為無法直接從後往前遍歷，該如何用 `O(1)` 空間解決？

Python

```
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def plusOne(self, head: ListNode) -> ListNode:
        # 建立 sentinel 哨兵節點，處理全為 9（如 9 -> 9 變成 1 -> 0 -> 0）的情況
        sentinel = ListNode(0, head)
        not_nine = sentinel
        
        # 1. 找到最右邊（最後一個）值不為 9 的節點
        curr = head
        while curr:
            if curr.val != 9:
                not_nine = curr
            curr = curr.next
            
        # 2. 將該節點的值加 1
        not_nine.val += 1
        
        # 3. 將該節點之後的所有 9 全部歸零
        curr = not_nine.next
        while curr:
            curr.val = 0
            curr = curr.next
            
        # 若哨兵節點被進位成 1，則回傳 sentinel；否則回傳原本的 head
        return sentinel if sentinel.val == 1 else sentinel.next
```
