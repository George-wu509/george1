
LeetCode 1899 三元组是一个由三个整数组成的数组。给你一个二维整数数组 `triplets` ，其中 `triplets[i] = [ai, bi, ci]` 表示第 `i` 个 **三元组** 。同时，给你一个整数数组 `target = [x, y, z]` ，表示你想要得到的 **三元组** 。

为了得到 `target` ，你需要对 `triplets` 执行下面的操作 **任意次**（可能 **零** 次）：

- 选出两个下标（下标从 0 开始）分别为 `i` 和 `j`（`i != j`），并 **更新** `triplets[j]` 为 `[max(ai, aj), max(bi, bj), max(ci, cj)]` 。
    

如果可以使 `target` 成为 `triplets` 的一个 **元素**（即 `triplets` 中存在某个元素等于 `target`），则返回 `true` ；否则，返回 `false` 。

**样例 1：** 输入：

```Python
triplets = [[2, 5, 3], [1, 8, 4], [1, 7, 5]]
target = [2, 7, 5]
```

输出：

```Python
True
```

解释： 执行下述操作：

- 选择第一个和最后一个三元组 `[[2, 5, 3], [1, 8, 4], [1, 7, 5]]` 。更新最后一个三元组为 `[max(2, 1), max(5, 7), max(3, 5)] = [2, 7, 5]` 。`triplets` 现在变成了 `[[2, 5, 3], [1, 8, 4], [2, 7, 5]]` 。 目标三元组 `[2, 7, 5]` 现在是 `triplets` 的一个元素，因此返回 `True` 。
    

**样例 2：** 输入：

```Python
triplets = [[3, 4, 5], [4, 5, 6]]
target = [3, 2, 5]
```

输出：

```Python
False
```

解释： 无法得到 `[3, 2, 5]` ，因为两个三元组在第二个位置上的值（4 和 5）都大于目标值 2 ，一旦参与合并只会导致结果更大，不可能变成 2 。

**样例 3：** 输入：

```Python
triplets = [[2, 5, 3], [2, 3, 4], [1, 2, 5], [5, 2, 3]]
target = [5, 5, 5]
```

输出：

```Python
True
```

解释： 依次合并第一个 `[2, 5, 3]`、第三个 `[1, 2, 5]` 和第四个 `[5, 2, 3]` 三元组，三个位置分别贡献了所需的 `5`，最终得到 `[5, 5, 5]` 。

```Python
# 解法一：貪心法（過濾非法三元組 + 集合記錄達標維度，NeetCode 經典寫法）
def mergeTriplets(self, triplets: list[list[int]], target: list[int]) -> bool:
    good = set()

    for t in triplets:
        # 只要有任何一個維度超過 target，這個三元組絕對不能選（否則最大值會被拉超過目標）
        if t[0] > target[0] or t[1] > target[1] or t[2] > target[2]:
            continue

        # 在安全的三元組中，記錄哪些維度剛好等於目標值
        for i, v in enumerate(t):
            if v == target[i]:
                good.add(i)

    return len(good) == 3
```


```Python
# 解法二：貪心法（維護當前合併後的最大三元組狀態）
def mergeTriplets(self, triplets: list[list[int]], target: list[int]) -> bool:
    curr = [0, 0, 0]

    for a, b, c in triplets:
        if a <= target[0] and b <= target[1] and c <= target[2]:
            curr[0] = max(curr[0], a)
            curr[1] = max(curr[1], b)
            curr[2] = max(curr[2], c)

    return curr == target
```

解釋（以解法一為例）: step1: 建立一個空集合 `good = set()`，用來記錄 `0, 1, 2` 三個維度是否已經找到可以湊出目標值的合法三元組 step2: 以 `triplets = [[2, 5, 3], [1, 8, 4], [1, 7, 5]]`、`target = [2, 7, 5]` 為例，逐一檢查每個三元組 `t` step3: 走訪 `[2, 5, 3]`，三個元素皆小於等於 `[2, 7, 5]`（合法），其中索引 `0` 的值 `2 == target[0]`，將 `0` 加入 `good`，目前 `good = {0}` step4: 走訪 `[1, 8, 4]`，發現中間元素 `8` 大於 `target[1]`（`7`），代表一旦合併它，第二個位置永遠不可能變回 `7`，直接 `continue` 跳過step5: 走訪 `[1, 7, 5]`，三個元素皆小於等於 `[2, 7, 5]`（合法），索引 `1` 的 `7` 與索引 `2` 的 `5` 皆等於目標值，將 `1, 2` 加入 `good`，此時 `good = {0, 1, 2}` step6: 迴圈結束後檢查 `len(good) == 3` 為 `True`，代表三個維度都能在不超標的前提下湊齊目標值

解釋（以解法二為例）: 直接維護一個初始為 `[0, 0, 0]` 的陣列 `curr` 模擬合併過程。只要某個三元組的三個數值都「小於等於」`target` 對應位置（代表它是無害的），就貪心地將它與 `curr` 取最大值合併；所有安全的三元組都合併完後，檢查 `curr` 是否剛好等於 `target`。

### **LeetCode 1899 - Merge Triplets to Form Target Triplet（合併三元組以形成目標三元組）**

這道題目是 NeetCode 150 中 **Greedy（貪心演算法）** 分類的經典題。題目看似需要搜尋「該選哪幾個三元組、按什麼順序合併」，但因為 `max` 運算具有單調不減（只會變大或維持不變，永遠不會變小）的特性，我們不需要做任何排列組合或回溯搜尋，只需一次線性掃描即可解決。

## **解法解析**

這道題的核心在於利用 `max` 操作的不可逆性，將問題轉化為 **「排除超標元素後的維度覆蓋問題」**。

### **思路**

1. **觀察規律（兩大關鍵性質）**
    
    - **性質一（超標即淘汰）**：合併操作的本質是對每個位置取 `max`。這意味著一旦某個位置的值超過了 `target` 的對應值，後續無論再跟誰合併，這個位置都**永遠不可能降回來**。因此，只要一個三元組中有**任何一個位置**嚴格大於 `target` 的對應值，這個三元組就絕對不能參與合併，必須直接丟棄。
        
    - **性質二（安全即可全選）**：對於剩下的「三個位置都小於等於 `target`」的合法三元組，將它們全部合併在一起是**完全安全**的——因為每個位置取 `max` 後，最大值頂多等於 `target`，絕不會超過 `target`。
        
2. **發現核心判斷邏輯**
    
    - 在所有「三個維度皆不超過 `target`」的合法三元組中，只要：
        
        - 至少有一個三元組滿足 `a == target[0]`
            
        - 至少有一個三元組滿足 `b == target[1]`
            
        - 至少有一個三元組滿足 `c == target[2]`
            
    - 那麼把這些合法三元組合併起來，最終結果必然精準等於 `[target[0], target[1], target[2]]`。
        
3. **代碼執行流程**
    
    - 初始化集合 `good = set()`（或初始化 `curr = [0, 0, 0]`）。
        
    - 遍歷 `triplets` 中的每一個三元組 `t`。
        
    - 先過濾掉 `t[0]` 大於 `target[0]`、或 `t[1]` 大於 `target[1]`、或 `t[2]` 大於 `target[2]` 的非法三元組。
        
    - 針對通過過濾的合法三元組，檢查三個位置是否等於 `target` 的對應元素，並記錄達標的維度索引。
        
    - 最後判斷三個維度是否全部達標（`len(good) == 3`）。
        

## **具體舉例**

假設 `triplets = [[2, 5, 3], [2, 3, 4], [1, 2, 5], [5, 2, 3]]`，`target = [5, 5, 5]`，變數變化如下：

|**遍歷索引**|**當前三元組 t**|**是否存在維度超過 [5, 5, 5]**|**匹配目標的維度**|**更新後 good 集合**|**解法二 curr 變化**|**狀態說明**|
|---|---|---|---|---|---|---|
|初始化|-|-|-|`{}`|`[0, 0, 0]`|尚未選取任何三元組|
|`0`|`[2, 5, 3]`|否（合法）|索引 `1`（值為 `5`）|`{1}`|`[2, 5, 3]`|貢獻了第 2 個維度的 `5`|
|`1`|`[2, 3, 4]`|否（合法）|無|`{1}`|`[2, 5, 4]`|安全但未達標，無副作用|
|`2`|`[1, 2, 5]`|否（合法）|索引 `2`（值為 `5`）|`{1, 2}`|`[2, 5, 5]`|貢獻了第 3 個維度的 `5`|
|`3`|`[5, 2, 3]`|否（合法）|索引 `0`（值為 `5`）|`{0, 1, 2}`|`[5, 5, 5]`|貢獻了第 1 個維度的 `5`|

遍歷結束後，`len(good) == 3`（且 `curr == [5, 5, 5]`），返回 `True`。

## **時間與空間複雜度分析**

- **時間複雜度：O(n)**
    
    - 其中 `n` 是陣列 `triplets` 的長度。我們只需遍歷每個三元組一次，每次比較與更新固定 3 個元素，屬於 `O(1)` 操作，因此總時間複雜度為 **O(n)**。
        
- **空間複雜度：O(1)**
    
    - 集合 `good` 最多只會儲存 `0, 1, 2` 三個整數（解法二的 `curr` 陣列固定長度為 3），不隨輸入規模 `n` 增長，因此額外空間複雜度為 **O(1)**。
        

## **其他解法**

### **1. 布林旗標追蹤法（Three Boolean Flags）**

- **思路**：
    
    - 與解法一完全相同的貪心邏輯，但不使用 `set()`，而是直接用三個布林變數 `found_x = found_y = found_z = False` 來記錄三個維度是否已找到匹配值，一旦三個都變成 `True` 就可以直接 `return True`（Early Return）。
        
- **優缺點**：
    
    - 省去建立 `set` 的微小開銷，且在資料量很大、前幾筆就能湊齊目標時能提早結束迴圈。
        
- **時間複雜度**：O(n)
    
- **空間複雜度**：O(1)
    

## **總結**

- **面試最推薦解法**：**貪心過濾法（Greedy Filtering）**，時間 `O(n)`，空間 `O(1)`，程式碼簡潔直觀且無需排序或額外資料結構。
    
- **核心思維**：遇到「合併操作為 `max` 或 `min`」的題目時，第一時間要想到**單調性（Monotonicity）**——超過目標上限的元素永遠無法被修正，必須直接過濾；而低於目標上限的元素則是完全無害的，可以放心全部納入合併。

### **進階變形：推廣到「任意長度 K 的元組」或「求最少合併次數」**

如果面試官追問：假設陣列裡不是三元組，而是**長度為 `k` 的元組**，並且要求回傳**湊出 `target` 所需選取的「最少元組數量」**（若無法湊出則回傳 `-1`），該如何修改？

Python

```
class Solution:
    def minTuplesToFormTarget(self, tuples: list[list[int]], target: list[int]) -> int:
        k = len(target)
        full_mask = (1 << k) - 1
        
        # 將每個合法元組轉成一個 bitmask，第 j 位為 1 代表該元組在維度 j 剛好等於 target[j]
        valid_masks = set()
        for t in tuples:
            if any(t[i] > target[i] for i in range(k)):
                continue
            mask = 0
            for i in range(k):
                if t[i] == target[i]:
                    mask |= (1 << i)
            if mask > 0:
                valid_masks.add(mask)

        # 使用 DP（狀態壓縮）求覆蓋 full_mask 所需的最少元組數（最少合併次數 = 元組數 - 1）
        dp = [float('inf')] * (full_mask + 1)
        dp[0] = 0
        for mask in valid_masks:
            for state in range(full_mask, -1, -1):
                if dp[state] != float('inf'):
                    dp[state | mask] = min(dp[state | mask], dp[state] + 1)

        return dp[full_mask] if dp[full_mask] != float('inf') else -
```
