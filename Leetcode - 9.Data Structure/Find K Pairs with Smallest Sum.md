给定两个以升序排列的整形数组 nums1 和 nums2, 以及一个整数 k。

定义一对值 (u,v)，其中第一个元素来自 nums1，第二个元素来自 nums2。找到和最小的 k 对数字 (u1,v1), (u2,v2) ... (uk,vk)。返回结果需要有序。

"""
示例 3:

输入: nums1 = [1,2], nums2 = [3], k = 3 
输出: [1,3],[2,3]
解释: 也可能序列中所有的数对都被返回:[1,3],[2,3]

```python
    def k_smallest_pairs(self, nums1, nums2, k):
        # write your code here
        n1, n2 = len(nums1), len(nums2)
        import heapq
        heap = [[nums1[0] + nums2[0], 0, 0]]
        seen = set((0, 0))
        res = []
        for i in range(min(k, n1 * n2)):
            _, idx1, idx2 = heapq.heappop(heap)
            res.append([nums1[idx1], nums2[idx2]])
            if idx1 < n1 - 1 and (idx1 + 1, idx2) not in seen:
                heapq.heappush(heap, [nums1[idx1 + 1] + nums2[idx2], idx1 + 1, idx2])
                seen.add((idx1 + 1, idx2))
            if idx2 < n2 - 1 and (idx1, idx2 + 1) not in seen:
                heapq.heappush(heap, [nums1[idx1] + nums2[idx2 + 1], idx1, idx2 + 1])
                seen.add((idx1, idx2 + 1))
        return res
```

這段程式碼採用 **最小堆疊（Min-Heap）+ 廣度優先搜尋（BFS / Dijkstra 思想）** 來尋找前 $k$ 個和最小的數對組合。

### 演算法核心原理

由於 `nums1` 與 `nums2` 皆為升序排列，如果將所有可能的數對組合看作一個二維網格 $(idx1, idx2)$：

- 全域最小和必然是左上角的組合 $(0, 0)$，即 `nums1[0] + nums2[0]`。
    
- 從任何一個位置 $(idx1, idx2)$ 出發，下一個比它大的候選組合只會出現於兩個方向：
    
    1. **右移一格**：$(idx1 + 1, idx2)$
        
    2. **下移一格**：$(idx1, idx2 + 1)$
        

為了始終取得當前未處理組合中的最小值，演算法利用 **Min-Heap** 動態維護當前候選組合，並使用哈希集合 `seen` 防止重複將相同的座標對放進 Heap 中。

### 程式碼逐行解析

- **`heap = [[nums1[0] + nums2[0], 0, 0]]`**：初始化堆疊，放入第一小組合 `[數值和, idx1, idx2]`。Python 的 `heapq` 會以陣列的第一個元素（數值和）作為排序依據。
    
- **`seen = set((0, 0))`**：記錄已入堆的座標對，避免重複計算。_(註：Python 語法中 `set((0, 0))` 會被視為迭代元素轉成 `{0}`，嚴謹寫法應為 `seen = {(0, 0)}` 或 `set([(0, 0)])`)_。
    
- **`for i in range(min(k, n1 * n2))`**：重複執行 $k$ 次（若總數對小於 $k$，則執行總數對數次）。
    
- **`_, idx1, idx2 = heapq.heappop(heap)`**：取出目前堆疊中和最小的組合，將實際數值 `[nums1[idx1], nums2[idx2]]` 放入 `res`。
    
- **檢查與推入右/下鄰居**：
    
    - 若 `idx1 + 1 < n1` 且未處理過：將右邊組合推入 Heap 並寫入 `seen`。
        
    - 若 `idx2 + 1 < n2` 且未處理過：將下邊組合推入 Heap 並寫入 `seen`。
        

### 實例推演：`nums1 = [1, 7, 11]`, `nums2 = [2, 4, 6]`, `k = 3`

#### 初始狀態

- `heap` = `[[3, 0, 0]]` （和為 $1+2=3$，座標 $(0,0)$）
    
- `seen` = `{(0, 0)}`
    
- `res` = `[]`
    

**1.第 1 次迭代 (i = 0)：**取出最小值 3。

- **Popped**: `[3, 0, 0]` $\rightarrow$ 數對 `[1, 2]`，加入 `res` (`res = [[1, 2]]`)。
    
- **延伸右鄰居 (1, 0)**: $7 + 2 = 9$，推入 Heap，`seen.add((1, 0))`。
    
- **延伸下鄰居 (0, 1)**: $1 + 4 = 5$，推入 Heap，`seen.add((0, 1))`。
    
- **當前 Heap**: `[[5, 0, 1], [9, 1, 0]]`
    

**2.第 2 次迭代 (i = 1)：**取出最小值 5。

- **Popped**: `[5, 0, 1]` $\rightarrow$ 數對 `[1, 4]`，加入 `res` (`res = [[1, 2], [1, 4]]`)。
    
- **延伸右鄰居 (1, 1)**: $7 + 4 = 11$，推入 Heap，`seen.add((1, 1))`。
    
- **延伸下鄰居 (0, 2)**: $1 + 6 = 7$，推入 Heap，`seen.add((0, 2))`。
    
- **當前 Heap**: `[[7, 0, 2], [9, 1, 0], [11, 1, 1]]`
    

**3.第 3 次迭代 (i = 2)：**取出最小值 7。

- **Popped**: `[7, 0, 2]` $\rightarrow$ 數對 `[1, 6]`，加入 `res` (`res = [[1, 2], [1, 4], [1, 6]]`)。
    
- **延伸右鄰居 (1, 2)**: $7 + 6 = 13$，推入 Heap，`seen.add((1, 2))`。
    
- **延伸下鄰居 (0, 3)**: $idx2 + 1 = 3$ 超出 `nums2` 邊界（長度為 3），不推入。
    
- **當前 Heap**: `[[9, 1, 0], [11, 1, 1], [13, 1, 2]]`
    

迴圈執行完 3 次後結束，最終傳回 `res = [[1, 2], [1, 4], [1, 6]]`。

### 複雜度分析

| **項目**    | **複雜度**       | **說明**                                     |
| --------- | ------------- | ------------------------------------------ |
| **時間複雜度** | $O(K \log K)$ | 每次彈出與加入元素時，Heap 大小最多不超過 $O(K)$，進行 $K$ 次操作。 |
| **空間複雜度** | $O(K)$        | Heap 與 `seen` 哈希集合最多儲存 $O(K)$ 個元素。         |
