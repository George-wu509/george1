
LeetCode 853 / LintCode 1479 在一条单行道上，有 `n` 辆车开往同一目的地，目的地是几英里以外的 `target` 。 给定两个整数数组 `position` 和 `speed` ，长度都是 `n` ，其中 `position[i]` 是第 `i` 辆车的位置， `speed[i]` 是第 `i` 辆车的速度（单位是英里/小时）。

一辆车永远不会超过前面的另一辆车，但它可以追上去，并以较慢车的速度在另一辆车旁边行驶。**车队** 是指并排行驶的一辆或几辆汽车。车队的速度是车队中 **最慢** 的车的速度。 即便一辆车在 `target` 目的地才赶上了一个车队，它们仍然会被视作是同一个车队。

返回到达目的地的 **车队数量** 。

**样例 1：** 输入：
```Python
target = 12
position = [10, 8, 0, 5, 3]
speed = [2, 4, 1, 1, 3]
```

输出：
```Python
3
```

解释：

- 从 10 和 8 开始的车会组成一个车队，它们在 12 处相遇（到达时间均为 1 小时）。
- 从 0 处开始的车无法追上其它车，所以它自己就是一个车队（到达时间为 12 小时）。
- 从 5 和 3 开始的车会组成一个车队，它们在 6 处相遇，之后以速度 1 共同行驶到 12 处（到达时间为 7 小时）。
- 因此，共有 3 个车队。

**样例 2：** 输入：
```Python
target = 10
position = [3]
speed = [3]
```

输出：
```Python
1
```

解释： 只有一辆车，因此只有一个车队。

**样例 3：** 输入：
```Python
target = 100
position = [0, 2, 4]
speed = [4, 2, 1]
```

输出：
```Python
1
```

解释：
- 从 0（速度 4）和 2（速度 2）出发的车在 4 处相遇，形成速度為 2 的车队。
- 随后该车队在 4 处又追上从 4（速度 1）出发的车，三辆车合并为一个车队，最终一起到达终点。


```Python
# 解法一：排序 + 單調棧（Monotonic Stack）
def carFleet(self, target: int, position: list[int], speed: list[int]) -> int:
    # 將每輛車的 (位置, 速度) 配對，並依照位置由大到小（離終點由近到遠）排序
    cars = sorted(zip(position, speed), reverse=True)
    stack = []  # 存放每個獨立車隊到達終點所需的時間（單調遞增）

    for pos, spd in cars:
        time = (target - pos) / spd
        # 若當前車輛到達終點的時間大於前方車隊，代表永遠追不上，形成新車隊
        if not stack or time > stack[-1]:
            stack.append(time)
        # 若 time 小於等於 stack[-1]，代表會在終點前（或剛好在終點）追上前車並合併，不需入棧

    return len(stack)
```


```Python
# 解法二：排序 + 單一變數滾動維護（省去 Stack 額外空間）
def carFleet(self, target: int, position: list[int], speed: list[int]) -> int:
    cars = sorted(zip(position, speed), reverse=True)
    fleets = 0
    slowest_time = 0.0  # 記錄目前前方車隊到達終點的最慢時間

    for pos, spd in cars:
        time = (target - pos) / spd
        if time > slowest_time:
            fleets += 1
            slowest_time = time

    return fleets
```

解釋: step1: 因為後車永遠不能「超車」，只會被前車「擋住」，所以一輛車的命運完全取決於 **排在它前面的車**。 step2: 以 `target = 12, position = [10, 8, 0, 5, 3], speed = [2, 4, 1, 1, 3]` 為例，先將車輛依位置從大到小排序（離終點最近排最前面）： `[(10, 2), (8, 4), (5, 1), (3, 3), (0, 1)]` step3: 計算每輛車「無阻礙到達終點的時間」`time = (target - pos) / spd`：

- 車 `(10, 2)`：`(12 - 10) / 2 = 1.0` -> `stack` 為空，入棧 -> `stack = [1.0]`
    
- 車 `(8, 4)`：`(12 - 8) / 4 = 1.0` -> `1.0` 小於等於 `stack[-1]`（1.0），在終點追上前車合併 -> `stack = [1.0]`
    
- 車 `(5, 1)`：`(12 - 5) / 1 = 7.0` -> `7.0` 大於 `1.0`，追不上前車，自成新車隊 -> `stack = [1.0, 7.0]`
    
- 車 `(3, 3)`：`(12 - 3) / 3 = 3.0` -> `3.0` 小於等於 `7.0`，中途追上 `(5, 1)` 並降速合併 -> `stack = [1.0, 7.0]`
    
- 車 `(0, 1)`：`(12 - 0) / 1 = 12.0` -> `12.0` 大於 `7.0`，追不上前車，自成新車隊 -> `stack = [1.0, 7.0, 12.0]` step4: 遍歷結束，`stack` 的長度 `3` 即為最終到達終點的車隊數量。
    

解釋: 核心規則：先按出發位置 **從近到遠（由大到小）** 排序，再比較「理論到達終點時間」。

如果後車的到達時間 **小於或等於** 前方車隊的到達時間，代表後車一定會在終點前（或剛好在終點）追上前車並與其合併；只有當後車到達時間 **嚴格大於** 前方車隊時，才會形成一個獨立的新車隊。

### **LeetCode 853 / LintCode 1479 - Car Fleet（車隊）**

這道題目是 **單調棧（Monotonic Stack）** 與 **貪心排序（Greedy Sorting）** 結合的經典題型（NeetCode 150 必考題）。題目表面上在模擬物理追趕過程，但只要換個視角，從「離終點最近的車」往回推算到達時間，就能把複雜的動態碰撞簡化為單純的時間比較。

## **解法解析**

這道題可以轉化為 **依位置排序後的「到達時間」單調遞增子序列** 問題來求解。

### **思路**

1. **觀察物理規律（關鍵洞察）**
    
    - 題目規定「**後車永遠不能超過前車**」。
        
    - 這意味著：**離終點最近的車（領頭車）完全不會受到任何後方車輛的影響**，它到達終點的時間是絕對固定的。
        
    - 接著看第二近的車：
        
        - 如果它單獨開到終點的時間 `t2` **小於等於** 領頭車的時間 `t1`，代表它開得比領頭車快，必定會在抵達終點前（或剛好在終點線上）追上領頭車，並被迫降速跟著領頭車一起走——**兩者合併為同一個車隊，且該車隊到達終點的時間依然是 `t1`**。
            
        - 如果 `t2` **大於** `t1`，代表它開得太慢，直到領頭車衝線都追不上——**它會成為一個全新車隊的領頭車**，並擋住後面可能追上它的車輛。
            
2. **為何使用「浮點數除法」而非整數除法？**
    
    - 計算時間時務必使用精確除法 `time = (target - pos) / spd`，**絕對不能使用整數除法 `//`**。
        
    - 例如 `target = 10`，車 A 在位置 `8` 速度 `3`（需 `0.666...` 小時），車 B 在位置 `6` 速度 `5`（需 `0.8` 小時）。若用 `//` 兩者都會變成 `0`，導致誤判為追上；實際上車 B 追不上車 A。
        
3. **代碼執行流程**
    
    - 使用 `zip(position, speed)` 將每輛車的位置與速度綁定，並依位置 **降序排列（`reverse=True`）**。
        
    - 初始化空棧 `stack = []`，用來記錄各個獨立車隊抵達終點的時間。
        
    - 依序計算每輛車的 `time = (target - pos) / spd`：
        
        - 若 `stack` 為空，或 `time` 大於 `stack[-1]`，將 `time` 推入 `stack`。
            
        - 否則（`time` 小於等於 `stack[-1]`），代表該車併入前方車隊，直接跳過。
            
    - 最終回傳 `len(stack)`。
        

## **具體舉例**

假設 `target = 12, position = [10, 8, 0, 5, 3], speed = [2, 4, 1, 1, 3]`，排序後為 `[(10, 2), (8, 4), (5, 1), (3, 3), (0, 1)]`，變數變化如下：

|**步驟**|**車輛 (pos, spd)**|**理論到達時間 time**|**與 stack[-1] 比較**|**stack 狀態**|**說明**|
|---|---|---|---|---|---|
|初始化|-|-|-|`[]`|建立空棧|
|1|`(10, 2)`|`(12-10)/2 = 1.0`|棧為空 -> 入棧|`[1.0]`|第 1 個車隊|
|2|`(8, 4)`|`(12-8)/4 = 1.0`|`1.0` 小於等於 `1.0` -> 合併|`[1.0]`|在終點追上 `(10, 2)`|
|3|`(5, 1)`|`(12-5)/1 = 7.0`|`7.0` 大於 `1.0` -> 入棧|`[1.0, 7.0]`|追不上，形成第 2 個車隊|
|4|`(3, 3)`|`(12-3)/3 = 3.0`|`3.0` 小於等於 `7.0` -> 合併|`[1.0, 7.0]`|在位置 6 追上 `(5, 1)`|
|5|`(0, 1)`|`(12-0)/1 = 12.0`|`12.0` 大於 `7.0` -> 入棧|`[1.0, 7.0, 12.0]`|追不上，形成第 3 個車隊|

最後返回 `len(stack)`，即 **`3`**。

## **時間與空間複雜度分析**

- **時間複雜度：O(n log n)**
    
    - 將 `n` 輛車依位置排序需要 $O(n \log n)$ 時間；隨後遍歷所有車輛計算時間並進出棧需要 $O(n)$ 時間。整體時間複雜度由排序主導，為 **O(n log n)**。
        
- **空間複雜度：O(n)**
    
    - 需要儲存配對後的 `cars` 陣列（長度 `n`）以及最壞情況下長度為 `n` 的 `stack`（當所有車都追不上前車時），因此空間複雜度為 **O(n)**。
        

## **其他解法**

### **1. 排序 + 單一變數追蹤（O(1) 輔助空間）**

- **思路**：
    
    - 觀察解法一可以發現，我們每次其實只需要跟 `stack[-1]`（即目前所有已處理車輛中 **最慢的到達時間**）做比較，並不需要存取更早之前的元素。
        
    - 因此可用一個浮點數變數 `slowest_time = 0.0` 取代 `stack`，每次遇到 `time` 大於 `slowest_time` 時，將車隊計數 `fleets += 1` 並更新 `slowest_time = time`。
        
- **時間複雜度**：O(n log n)
    
- **空間複雜度**：O(n)（儲存排序陣列；若不計排序陣列則為 $O(1)$）
    

### **2. 計數排序 / 桶排序優化（當 `target` 較小時）**

- **思路**：
    
    - 若題目限制 `target` 範圍不大（例如 `target` 小於等於 $10^5$），且所有車的初始位置互不相同，可以直接建立一個長度為 `target` 的陣列 `time_arr`，將每輛車的到達時間填入 `time_arr[pos]`。
        
    - 接著直接從 `target - 1` 倒序遍歷到 `0`，省去 $O(n \log n)$ 的比較排序。
        
- **時間複雜度**：O(n + target)
    
- **空間複雜度**：O(target)
    

## **總結**

- **最佳解法（通用首選）**：**依位置降序排序 + 單一變數 `slowest_time`（或單調棧）**，時間 $O(n \log n)$，空間 $O(n)$，邏輯清晰且不受 `target` 大小限制。
    
- **避坑重點 1**：必須使用 **精確浮點數除法** `(target - pos) / spd`（或在交叉相乘時用整數比較 `(target - pos1) * spd2` 與 `(target - pos2) * spd1` 來完全避免浮點數精度誤差）。
    
- **避坑重點 2**：在終點線 `target` 處剛好追上也算同一個車隊，因此合併條件包含等號（`time` 小於等於 `slowest_time`）。

### **進階變體練習：LeetCode 1776 - Car Fleet II（計算每輛車追上前車的精確碰撞時間）**

如果題目進階為：當後車追上前車後，後車會「融入」前車並消失（或與前車合體以更慢速度前進），要求回傳 **每一輛車追上前方車輛所需的精確時間**（追不上則回傳 `-1`）：

Python

```
class Solution:
    def getCollisionTimes(self, cars: list[list[int]]) -> list[float]:
        # cars[i] = [position, speed]，題目已按 position 嚴格遞增給定
        n = len(cars)
        ans = [-1.0] * n
        stack = []  # 存放後方車輛可能追上的「前車索引」

        # 從最靠近終點的車開始倒序遍歷
        for i in range(n - 1, -1, -1):
            pos, spd = cars[i]

            # 若前車速度 >= 當前車速度，永遠追不上，將前車彈出
            # 或者：當前車追上前車的時間 >= 前車自己撞上更前方車輛的時間，代表前車會先被合併，也將其彈出
            while stack:
                j = stack[-1]
                pos_j, spd_j = cars[j]
                if spd <= spd_j:
                    stack.pop()
                else:
                    collide_time = (pos_j - pos) / (spd - spd_j)
                    if ans[j] != -1.0 and collide_time >= ans[j]:
                        stack.pop()
                    else:
                        break

            # 棧頂即為當前車第一個能成功追上的目標車輛
            if stack:
                j = stack[-1]
                ans[i] = (cars[j][0] - pos) / (spd - cars[j][1])

            stack.append(i)

        return ans
```
