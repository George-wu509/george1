Anthropic 官方的 Skill 撰寫指南，核心其實只有一句話：Claude 已經很聰明，只教它不知道的事。這支影片用不到 3 分鐘、零程式碼，帶你看懂 Skill 是什麼。它就像一個資料夾，裝著說明書、範本和小程式，教一次就能一直用。平常 Claude 只看每本手冊的書背，要用時才翻開內文，所以裝上一百個也不會塞爆。接著拆解5 個重點：寫短、把書背寫清楚、看路況給自由度、先出考卷再寫課本、讓 Claude 教 Claude。

最後看看 X 上的實戰：Anthropic 為新模型刪掉八成系統提示，也有人把 Skill 從一千六百多行砍到一百八十三行，功能完全一樣。到了 Opus 5.5 這一代，少即是多。收藏起來，下次寫 Skill 前再看一次。
